Cette notice concerne le site PrintDeck, l’installateur dans le navigateur et les échanges avec l’assistance. Pour toute question sur la confidentialité, contactez PrintDeck à l’adresse support@printdeck.xyz.

Visites du site

PrintDeck n’utilise ni traceurs publicitaires ni outils d’analyse des visites. Ce site est hébergé sur GitHub Pages, qui enregistre les adresses IP des visiteurs à des fins de sécurité.

Le lecteur vidéo charge ses icônes depuis cdn.plyr.io. L’installateur charge des bibliothèques depuis unpkg.com et cdn.jsdelivr.net et télécharge le micrologiciel depuis ce site ou GitHub. Ces requêtes transmettent votre adresse IP et des informations techniques au fournisseur concerné.

Les fournisseurs externes peuvent traiter les données des requêtes en dehors de l’Espace économique européen. Leurs notices de confidentialité décrivent le traitement, la conservation et les garanties des transferts internationaux.

  • Déclaration de confidentialité de GitHub
  • Politique de confidentialité de jsDelivr

Stockage du navigateur

Le site utilise localStorage pour mémoriser votre langue et l’apparence. Le lecteur vidéo enregistre aussi les préférences de lecture et peut mettre ses icônes en cache. Ces informations restent dans votre navigateur et PrintDeck ne les utilise ni pour la publicité ni pour l’analyse des visites.

PrintDeck ne définit pas d’expiration automatique pour ces données. Vous pouvez les supprimer en effaçant les données de ce site dans les paramètres du navigateur. Vos préférences enregistrées seront alors réinitialisées.

Installateur dans le navigateur

L’installateur télécharge le micrologiciel et l’écrit directement depuis votre navigateur sur le périphérique USB que vous sélectionnez. L’accès au périphérique nécessite votre autorisation dans le navigateur.

Messages à l’assistance

Lorsque vous écrivez à PrintDeck, nous recevons votre adresse e-mail, votre message et les pièces jointes que vous choisissez d’envoyer. Nous utilisons Microsoft 365 (Office 365) pour la messagerie d’assistance et traitons ces échanges pour répondre à votre demande et examiner les problèmes signalés.

Déclaration de confidentialité de Microsoft

Nous traitons les demandes d’assistance sur la base de notre intérêt légitime à répondre aux questions et à résoudre les problèmes. Si votre demande concerne la conclusion d’un contrat avec nous, nous traitons les informations nécessaires pour prendre des mesures à votre demande avant ce contrat.

Nous conservons les échanges aussi longtemps que nécessaire pour traiter votre demande et poursuivre la conversation qui s’y rapporte. Vous pouvez nous contacter pour demander leur suppression.

Les rapports de compatibilité ne sont pas envoyés automatiquement : vous décidez de les transmettre ou non par e-mail. Les tickets GitHub sont publics. N’y incluez pas de mots de passe, de codes d’accès ni d’autres informations privées.

Vos droits

Selon la base juridique applicable, vous pouvez demander l’accès à vos données personnelles, leur rectification, leur suppression, la limitation du traitement ou leur portabilité, et vous opposer au traitement fondé sur des intérêts légitimes. Adressez vos demandes à PrintDeck à l’adresse e-mail ci-dessus. Vous pouvez aussi déposer une réclamation auprès de votre autorité de protection des données, notamment l’UODO en Pologne.
