VOUS DÉCIDEZ QUAND IL ÉCOUTE

Activez-le dans l’interface web de PrintDeck.

Pour PrintDeck sur AMOLED 1.75″ et LCD 1.54″ avec prise en charge de Hi ESP!. Non disponible sur les appareils KNOMI.

  1. 01

    Ouvrez le panneau web de PrintDeck

    Connectez votre téléphone ou ordinateur au même réseau Wi-Fi. Ouvrez l’adresse affichée sur l’écran Web Config de l’appareil.

  2. 02

    Choisissez HI ESP!

    Dans le panneau web de PrintDeck, ouvrez Paramètres de l’appareil, puis HI ESP!. Lisez les informations sur le microphone et la confidentialité.

  3. 03

    Activez l’écoute

    Sélectionnez Activer Hi ESP!. L’état « Activé » et l’indicateur HI ESP! en haut de la page confirment l’activation. PrintDeck mémorise votre choix.

  4. 04

    Vérifiez le son et l’imprimante

    Activez le son avec un volume supérieur à zéro pour entendre les réponses. Sélectionnez une imprimante en ligne et réglez votre fuseau horaire pour l’heure de fin.

VOTRE VOIX RESTE ICI

Votre voix. Votre vie privée.

Votre voix reste sur PrintDeck. Aucun enregistrement conservé, aucun son envoyé à l’imprimante ou au cloud. Même la réponse vocale est créée sur l’appareil, sans compte de service vocal.

C’est vous qui choisissez

Hi ESP! est désactivé par défaut. Une fois activé, le microphone écoute en continu la phrase de réveil, même pendant l’économiseur d’écran ou avec l’écran éteint.

Désactivez-le à tout moment

Dans le panneau web de PrintDeck → Paramètres de l’appareil → HI ESP!, sélectionnez Désactiver Hi ESP!. Le microphone cesse d’écouter. Couper le son du haut-parleur rend seulement les réponses muettes ; cela ne coupe pas le microphone.

Les données restent chez vous

PrintDeck consulte l’imprimante sélectionnée via votre réseau domestique. Comprendre votre voix ne nécessite pas internet ; les informations à jour nécessitent une connexion à l’imprimante.
