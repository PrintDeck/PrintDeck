UN PETIT CONTRAT EN LECTURE SEULE

Des données utiles.
Aucune interface de commande.

L’API expose les informations de l’appareil, l’identité de l’imprimante, l’état, les buses et les emplacements de matériau. Elle ne peut ni démarrer, ni mettre en pause, ni annuler une impression.

COMMENCEZ SUR VOTRE RÉSEAU LOCAL

Depuis Web Config
jusqu’à votre première requête.

  1. 01

    Ouvrez Unified Printer API

    Dans Web Config, ouvrez Paramètres de l’appareil et choisissez Unified Printer API au-dessus de Sauvegarde et restauration.

  2. 02

    Activez et copiez le jeton

    PrintDeck génère un jeton d’accès aléatoire et le stocke localement sur l’appareil.

  3. 03

    Envoyez l’authentification Bearer

    Utilisez le jeton dans l’en-tête Authorization de chaque requête adressée à l’adresse IP de PrintDeck.

  4. 04

    Récupérez des données unifiées

    Lisez les listes d’imprimantes ou leur état et utilisez la même structure JSON pour les types d’imprimantes pris en charge.

PÉRIMÈTRE DU RÉSEAU LOCAL DE CONFIANCE

Les secrets de votre imprimante
restent derrière PrintDeck.

L’API unifiée pour imprimantes ne renvoie jamais les mots de passe d’imprimante, codes d’accès LAN, numéros de série, mots de passe Wi-Fi, images de caméra ni données brutes du constructeur. Gardez PrintDeck sur un réseau local de confiance et ne redirigez pas son port vers Internet.

Aucun webhook. Aucun relais cloud. Aucun endpoint de commande d’imprimante.
