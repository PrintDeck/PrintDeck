Home Assistant avec MQTT

Connectez PrintDeck à Mosquitto. Choisissez la découverte MQTT automatique ou une connexion MQTT dans l’intégration PrintDeck de HACS.

  1. 01

    Préparer Mosquitto

    Installez l’application serveur Mosquitto dans Home Assistant ou utilisez votre serveur local existant. Configurez l’intégration MQTT dans Home Assistant et créez des identifiants pour PrintDeck. Les deux doivent se connecter au même serveur.

  2. 02

    Connecter PrintDeck

    Ouvrez Web Config > Paramètres de l’appareil > Unified API. Activez MQTT et saisissez l’adresse, le port et les identifiants du serveur. Utilisez une adresse accessible depuis PrintDeck, pas le nom interne de l’application HA. Enregistrez puis vérifiez la connexion. HTTP et MQTT s’activent indépendamment.

  3. 03

    Choisir une méthode dans Home Assistant

    Pour l’intégration MQTT de Home Assistant, activez la découverte MQTT de Home Assistant dans PrintDeck. Les appareils et entités apparaissent automatiquement, sans HACS. Pour l’intégration PrintDeck, installez-la via HACS, ajoutez PrintDeck et choisissez MQTT. Laissez alors la découverte désactivée pour éviter les doublons.

  4. 04

    Utiliser les mêmes automatisations

    Sélectionnez les nouvelles entités d’état et de progression dans les blueprints existants de fin d’impression et de paliers. Avant de quitter HTTP, adaptez les entités des tableaux de bord et automatisations. N’utilisez les deux méthodes pour une même imprimante que si vous souhaitez deux ensembles d’entités.

Dans la configuration MQTT de HACS, collez la racine des sujets MQTT affichée dans Web Config de PrintDeck. Home Assistant utilise sa connexion au serveur déjà configurée ; ne saisissez pas à nouveau le mot de passe. Pour passer entre HTTP et MQTT dans une intégration PrintDeck existante, utilisez Reconfigurer : l’identité des entités est conservée. Le passage entre découverte MQTT générique et HACS nécessite de sélectionner les nouvelles entités dans vos automatisations.

Des données en lecture seule communes

MQTT utilise les mêmes données normalisées que HTTP : identité, état, progression, durées, températures, outils et matériaux. Seule l’imprimante sélectionnée possède une connexion complète en direct ; les autres suivent l’actualisation de la liste. Les données inconnues ou anciennes sont signalées. MQTT n’ajoute ni commandes d’imprimante ni vidéo.

Connexion et rétablissement

TLS vérifie le certificat et le nom du serveur. Ajoutez votre CA si nécessaire. Les secrets restent dans PrintDeck ; des champs mot de passe et CA vides les conservent. Après un redémarrage du serveur ou de HA, PrintDeck se reconnecte et publie des données récentes. Sa disponibilité est distincte de l’état de chaque imprimante.

Supprimer les anciennes entrées de découverte

Avant de changer de serveur ou de passer à HACS MQTT, désactivez la découverte pendant que l’ancien serveur reste accessible et attendez la fin du nettoyage. S’il est inaccessible, ses entrées conservées peuvent nécessiter une suppression manuelle. Renommer conserve l’identité ; supprimer un profil retire sa configuration de découverte.

Conserver l’intégration HTTP

Le guide HTTP et l’installation via HACS restent disponibles. MQTT est un choix de connexion supplémentaire.
