DE KNOMI2 À PRINTDECK

Une installation simple
dans le navigateur.

Le pilote USB provient du matériel WCH USB-série de KNOMI2, et non de PrintDeck. Nous avons rendu tout le reste clair et guidé dans votre navigateur de bureau.

  1. 01

    Connectez en USB-C

    Utilisez un câble USB-C de données et connectez KNOMI2 directement à votre ordinateur. Évitez les concentrateurs USB lors de la première installation.

  2. 02

    Laissez le système le détecter

    Windows installe généralement le pilote WCH automatiquement via Windows Update.

    Linux fonctionne immédiatement sur la plupart des distributions ; seules les autorisations du port série peuvent demander un réglage.

    macOS peut nécessiter le pilote WCH officiel et une autorisation dans Confidentialité et sécurité avant que Chrome puisse détecter KNOMI2.

  3. 03

    Installer PrintDeck

    Ouvrez le programme d’installation dans Chrome ou Edge sur ordinateur. Sélectionnez KNOMI2, choisissez Première installation / Réinitialisation d’usine, confirmez l’effacement complet et attendez 100 %. L’écran redémarre avec sa nouvelle expérience PrintDeck.

VOS QUESTIONS SUR KNOMI2

Sachez ce qui change.
Sans modifier votre imprimante.

Des réponses claires sur l’installation de PrintDeck, la personnalisation des réactions et l’utilisation des données déjà fournies par votre imprimante.

Dois-je modifier printer.cfg ou installer des macros propres à KNOMI ?

Non. PrintDeck est conçu pour lire les données d’état standard déjà fournies par votre imprimante via Moonraker. L’état d’impression, la progression, les températures, les couches et les temps ne nécessitent aucune macro PrintDeck ni modification de G28, du nivellement du plateau ou d’autres macros de l’imprimante. Les réactions très spécifiques n’apparaissent que lorsque l’imprimante fournit des informations suffisamment fiables pour les identifier.

Puis-je ajouter mes propres GIF sans PlatformIO ni reconstruire le micrologiciel ?

Oui. Ouvrez Web Config, choisissez un emplacement de réaction disponible, téléversez votre GIF et prévisualisez-le avant de l’appliquer. Vous pouvez personnaliser chaque emplacement séparément ou restaurer l’animation intégrée à tout moment, sans tableau C, projet VS Code ni reconstruction du micrologiciel.

PrintDeck affiche-t-il des informations utiles sur l’impression, et pas seulement des animations ?

Oui. Faites glisser depuis l’écran de réaction pour consulter la progression, le temps restant, les couches, les températures actuelles et cibles, les outils actifs ainsi que les données supplémentaires de mouvement, de ventilation ou de chauffage fournies par l’imprimante. Les installations Moonraker peuvent afficher les informations de douze extrudeurs au maximum.

Puis-je consulter la caméra de mon imprimante sans service cloud ?

Oui, lorsque l’imprimante et sa source de caméra locale sont prises en charge. PrintDeck se connecte directement à la caméra sur votre réseau local tant que la vue caméra est ouverte. Aucun compte cloud PrintDeck ni relais de caméra distant n’est nécessaire.

Devrai-je reflasher KNOMI2 par USB après chaque mise à jour ?

Normalement, non. La première installation de PrintDeck utilise l’installateur guidé dans le navigateur. Les versions ultérieures prises en charge peuvent être installées sans fil, avec une mise à jour USB préservant la configuration comme option de récupération.
