Avant de commencer

Connectez-vous en trois étapes

Vous devez disposer de Klipper et Moonraker en fonctionnement, de l’adresse et du port de Moonraker, ainsi que d’une clé API si votre serveur l’exige. PrintDeck doit pouvoir joindre cette adresse sur votre réseau local.

  1. 01

    Vérifiez Moonraker

    Ouvrez votre interface habituelle et vérifiez que l’imprimante est connectée. Utilisez l’adresse de Moonraker et son port API, généralement 7125, plutôt que l’adresse d’un tableau de bord cloud.

  2. 02

    Ajoutez la connexion

    Dans Web Config, ouvrez Mes imprimantes → Ajouter une imprimante → Autres imprimantes. Saisissez l’adresse et choisissez Klipper / Moonraker dans Type de connexion. Ajoutez la clé API si nécessaire.

  3. 03

    Vérifiez et connectez

    Vérifiez l’imprimante détectée, donnez-lui un nom et choisissez Vérifier et ajouter. Sélectionnez le profil en ligne pour ouvrir son tableau de bord.

Questions et réponses

Est-ce une connexion à Mainsail ou Fluidd ?

PrintDeck se connecte à Moonraker, le service local utilisé par des interfaces comme Mainsail et Fluidd. Vous pouvez continuer à utiliser votre interface habituelle en parallèle de PrintDeck.

Toutes les imprimantes Klipper fournissent-elles chaque détail ?

Non. Les données sur les outils, le filament et les mouvements dépendent de votre configuration. Les miniatures doivent être présentes dans les métadonnées des fichiers de Moonraker.
