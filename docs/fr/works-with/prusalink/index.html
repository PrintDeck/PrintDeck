Une vue claire du travail

Consultez l’état de l’imprimante, le travail en cours, la progression et les estimations de temps disponibles, avec les températures de buse et de plateau fournies.

Utilisez votre connexion existante

Connectez-vous avec l’identifiant et le mot de passe PrusaLink, ou utilisez une clé API si votre configuration PrusaLink le permet.

Avant de commencer

Connectez-vous en trois étapes

Activez PrusaLink pour votre imprimante et vérifiez qu’il s’ouvre depuis un autre appareil du même réseau. Préparez son adresse locale et les identifiants PrusaLink ou la clé API correspondants.

  1. 01

    Ouvrez PrusaLink en local

    Suivez les instructions de Prusa pour votre modèle. Copiez l’adresse locale et les identifiants de connexion depuis votre imprimante ou la configuration PrusaLink.

  2. 02

    Choisissez PrusaLink

    Dans Web Config, ouvrez Mes imprimantes → Ajouter une imprimante → Autres imprimantes. Saisissez l’adresse et sélectionnez PrusaLink dans Type de connexion.

  3. 03

    Vérifiez vos identifiants

    Choisissez Identifiant et mot de passe ou Clé API selon votre configuration. Saisissez les informations, choisissez Vérifier et ajouter, puis sélectionnez le profil en ligne.

Questions et réponses

Ai-je besoin d’un compte Prusa Connect ?

Cette connexion utilise PrusaLink sur votre réseau local. Saisissez l’adresse locale et les identifiants PrusaLink, et non ceux de votre compte Prusa Connect.

Toutes les versions de PrusaLink fournissent-elles les mêmes données ?

Les relevés disponibles varient selon l’imprimante et la version de PrusaLink. PrintDeck affiche les informations fournies par la connexion locale.
