USB driver may be required

KNOMI2 uses a WCH USB-to-serial bridge. Unlike the Waveshare screens, it does not use a standard native USB connection, so a WCH driver may be required before Chrome can see it. This comes from the KNOMI2 hardware design, not PrintDeck. Click below to start installation and open Chrome's protected device list. Look for WCH USB Serial (cu.wchusbserial…), USB-SERIAL CH340 (COM…) or /dev/ttyUSB…. If you do not see one, close the list, choose your system and follow the driver instructions below.

FIRST INSTALLATION / FACTORY RESET

Prepare and connect your screen

  1. Get a USB-C data cable. It must transfer data, not only charge devices. The cable supplied with a phone or external drive usually works.
  2. Connect the screen directly to your computer. Plug the USB-C end into the Waveshare display and the other end into your PC or Mac. Avoid a USB hub for the first installation.
  3. Connect KNOMI2 directly to your computer. Use a USB-C data cable and avoid a USB hub for the first installation.
  4. Start the installer below. Choose the serial device whose name contains ESP32, USB, UART, JTAG or CP210. Confirm the full erase when asked, then wait until installation reaches 100%.
  5. Start the installer below. Choose WCH USB Serial (cu.wchusbserial…), USB-SERIAL CH340 (COM…) or /dev/ttyUSB…. Confirm the full erase when asked, then wait until installation reaches 100%.
USB access requires this page to be opened over HTTPS.
If no device appears: unplug the cable. Hold the display's BOOT button, reconnect USB-C, release BOOT after two seconds and try again.
If KNOMI2 does not appear: close the device list, follow the USB driver instructions in the red section above, reconnect KNOMI2 and start the installation again.
  1. Wait for the Wi-Fi setup screen. The display will show a QR code and create a temporary network named PrintDeck-XXXXXX, with a unique ending for that screen.
  2. Connect a phone or computer to your screen. Scan the QR code with your phone's camera, or select the exact open network shown on PrintDeck. Wi-Fi setup should open automatically. No password is required, and it is normal for the device to say that this network has no internet.
  3. If setup does not open automatically. While still connected to the PrintDeck setup network, enter http://printdeck.local in your browser. If needed, use http://192.168.4.1 as the fallback address.
  4. Connect your screen to your normal Wi-Fi. Use Scan networks, select your network, enter its password and save. Printer details are added separately after Wi-Fi setup.
  5. Reconnect your phone or computer to its normal Wi-Fi. Your screen restarts on an empty My Printers screen and shows its Web Config address.
  6. Add your printer from Web Config. Open the address shown on your screen, add your Klipper or Bambu Lab printer and save the connection.

Factory reset: this option erases all settings stored on your screen. It does not change anything on your printer or its controller.

FIRMWARE UPDATE

Update without losing your settings

Update a working screen over USB without erasing saved Wi-Fi, printers, appearance or other configuration. This updater writes the application and boot selection only; the NVS settings partition is never erased.

  1. Connect the screen directly to this computer with a USB-C data cable.
  2. Connect KNOMI2 directly to this computer with a USB-C data cable.
  3. Select the firmware version above. The newest release is selected by default; an older version can be chosen for rollback.
  4. Start the USB update below. Choose the ESP32, USB, UART, JTAG or CP210 serial device when prompted.
  5. Start the USB update below. Choose WCH USB Serial (cu.wchusbserial…), USB-SERIAL CH340 (COM…) or /dev/ttyUSB… when prompted.
  6. Wait for the screen to restart. Do not disconnect USB while the update progress is visible.
If KNOMI2 is missing: follow the USB driver instructions in the red section above, reconnect it, then start the update again.

Preparing update…
Your configuration stays safe: this path cannot request or perform a full-device erase. If the screen cannot be updated, use First installation / Factory reset only as a recovery option.

Prefer updating over Wi-Fi?

Open your screen's local Web Config page, choose Check for updates, then confirm Install update. The Wi-Fi updater also preserves saved settings.
