UN PEQUEÑO CONTRATO DE SOLO LECTURA

Datos útiles.
Sin superficie de control.

La API expone información del dispositivo, identidad de la impresora, estado, boquillas y ranuras de material. No puede iniciar, pausar ni cancelar una impresión.

EMPIEZA EN TU RED LOCAL

Desde Web Config
hasta tu primera solicitud.

  1. 01

    Abre Unified Printer API

    En Web Config, abre Ajustes del dispositivo y elige Unified Printer API encima de Copia de seguridad y restauración.

  2. 02

    Activa y copia el token

    PrintDeck genera un token de acceso aleatorio y lo guarda localmente en el dispositivo.

  3. 03

    Envía autenticación Bearer

    Usa el token en la cabecera Authorization de cada solicitud a la dirección IP de PrintDeck.

  4. 04

    Obtén datos unificados

    Lee listas de impresoras o su estado y utiliza la misma estructura JSON para los tipos de impresora compatibles.

LÍMITE DE LAN DE CONFIANZA

Los secretos de tu impresora
permanecen detrás de PrintDeck.

La API unificada de impresoras nunca devuelve contraseñas de impresora, códigos de acceso LAN, números de serie, contraseñas Wi-Fi, fotogramas de cámara ni datos brutos del fabricante. Mantén PrintDeck en una red local de confianza y no reenvíes su puerto a Internet.

Sin webhooks. Sin relé en la nube. Sin endpoints de control de impresora.
