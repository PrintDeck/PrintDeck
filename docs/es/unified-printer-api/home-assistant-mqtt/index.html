Home Assistant con MQTT

Conecta PrintDeck a Mosquitto. Elige la detección MQTT automática o una conexión MQTT en la integración PrintDeck de HACS.

  1. 01

    Prepara Mosquitto

    Instala la aplicación del servidor Mosquitto en Home Assistant o usa tu servidor local actual. Configura la integración MQTT en Home Assistant y crea credenciales para PrintDeck. Ambos deben conectarse al mismo servidor.

  2. 02

    Conecta PrintDeck

    Abre Web Config > Ajustes del dispositivo > Unified API. Activa MQTT e introduce dirección, puerto y credenciales del servidor. Usa una dirección accesible desde PrintDeck, no el nombre interno de la aplicación de HA. Guarda y comprueba la conexión. HTTP y MQTT se activan de forma independiente.

  3. 03

    Elige una vía en Home Assistant

    Para la integración MQTT de Home Assistant, activa la detección MQTT de Home Assistant en PrintDeck. Los dispositivos y entidades aparecen automáticamente, sin HACS. Para la integración PrintDeck, instálala desde HACS, añade PrintDeck y elige MQTT como conexión. En este caso, mantén la detección desactivada para evitar duplicados.

  4. 04

    Usa las mismas automatizaciones

    Selecciona las nuevas entidades de estado y progreso en los blueprints existentes de fin de impresión e hitos. Antes de cambiar desde HTTP, actualiza las entidades de paneles y automatizaciones. No uses ambas vías para la misma impresora salvo que quieras dos conjuntos de entidades.

En la configuración MQTT de HACS, pega el tema raíz MQTT de Web Config de PrintDeck. Home Assistant usa su conexión configurada al servidor; no vuelvas a introducir la contraseña. Para cambiar entre HTTP y MQTT en una integración PrintDeck existente, usa Reconfigurar. Así se conservan las identidades de las entidades. Al pasar entre detección MQTT genérica y HACS, selecciona las nuevas entidades en tus automatizaciones.

Datos de solo lectura compartidos

MQTT usa los mismos datos normalizados que HTTP: identidad, estado, progreso, tiempos, temperaturas, herramientas y materiales. Solo la impresora seleccionada mantiene una conexión completa en directo; las demás siguen el intervalo de actualización de la lista. Los datos desconocidos o antiguos se indican como tales. MQTT no añade controles ni vídeo de cámaras.

Conexión y recuperación

TLS verifica el certificado y nombre del servidor. Añade tu CA si hace falta. Los secretos permanecen en PrintDeck; dejar vacíos los campos de contraseña y CA los conserva. Tras reiniciar el servidor o HA, PrintDeck vuelve a conectarse y publica datos recientes. La disponibilidad de PrintDeck es independiente del estado de cada impresora.

Elimina entradas antiguas de detección

Antes de cambiar de servidor o pasar a HACS MQTT, desactiva la detección con el servidor anterior accesible y espera a que termine la limpieza. Si no está accesible, quizá debas eliminar manualmente sus entradas retenidas. Cambiar el nombre mantiene la identidad; borrar un perfil elimina su configuración de detección.

Conserva la integración HTTP

La guía HTTP y la instalación por HACS siguen disponibles. MQTT es una opción de conexión adicional.
