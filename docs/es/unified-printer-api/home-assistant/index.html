LA IDEA

PrintDeck traduce.
Home Assistant reacciona.

PrintDeck ya comprende el protocolo específico de la impresora. Home Assistant solo tiene que consultar Unified Printer API a un intervalo seguro y utilizar los valores devueltos como entidades normales.

01

Impresión terminada

Enciende una lámpara, envía una notificación al teléfono o anuncia que la pieza está lista.

02

Hitos de progreso

Reacciona cuando el progreso supere el 25 %, 50 % o 75 % para cambiar una luz indicadora o actualizar un panel.

03

Trabajo pausado o detenido

Reacciona ante trabajos pausados, fallidos o cancelados antes de volver al taller.

04

Vista general del taller

Muestra la conexión, las temperaturas, el tiempo restante y la capa actual en un único panel local.

UN ESTADO, UNA LUZ

Enciende una luz
cuando termine una impresora.

Este primer ejemplo supervisa la fase de una impresora y enciende una sola entidad de luz. Sustituye la dirección IP, el ID de impresora y la entidad de luz de ejemplo por tus propios valores.

  1. 01

    Activa la API

    Abre Web Config en PrintDeck, elige Unified Printer API, actívala y copia el token de acceso generado.

  2. 02

    Busca el ID de la impresora

    Solicita la lista de impresoras y anota el ID de la impresora que quieres supervisar.

    Terminal
    curl http://PRINTDECK-IP/v1/printers \
  -H 'Authorization: Bearer pd_your_token_here'
  3. 03

    Guarda el token en secrets.yaml

    Incluye la palabra Bearer en el valor del secreto.

    secrets.yaml
    printdeck_api_bearer: "Bearer pd_your_token_here"
  4. 04

    Añade el sensor de fase

    Esto realiza una solicitud cada 10 segundos. Cambia PRINTDECK-IP y el ID de impresora 1 en la URL.

    configuration.yaml
    rest:
  - resource: "http://PRINTDECK-IP/v1/printers/1/status"
    method: GET
    headers:
      Authorization: !secret printdeck_api_bearer
    scan_interval: 10
    timeout: 5
    sensor:
      - name: "PrintDeck Phase"
        unique_id: printdeck_printer_1_phase
        value_template: "{{ value_json.status.job.phase }}"
  5. 05

    Comprueba y reinicia Home Assistant

    Valida el YAML en Herramientas para desarrolladores, reinicia Home Assistant y comprueba que la entidad PrintDeck Phase tenga un valor.

  6. 06

    Añade la automatización

    Sustituye light.living_room por el ID de entidad de tu lámpara.

    automations.yaml
    - alias: "PrintDeck - light on when print completes"
  id: printdeck_light_on_when_print_completes
  triggers:
    - trigger: state
      entity_id: sensor.printdeck_phase
      to: "completed"
  conditions:
    - condition: template
      value_template: >-
        {{ trigger.from_state is not none and
           trigger.from_state.state in ['preparing', 'printing', 'paused'] }}
  actions:
    - action: light.turn_on
      target:
        entity_id: light.living_room
  mode: single
  7. 07

    Inicia una impresión de prueba corta

    Observa cómo la entidad de fase pasa a completed. Si la lámpara no se enciende, abre el seguimiento de la automatización para ver los resultados del disparador y de la condición.

TODOS LOS ESTADOS NORMALIZADOS

Utiliza fases generales
o actividades detalladas.

La fase del trabajo es la mejor opción para la mayoría de las automatizaciones. La actividad del trabajo expone las actividades detalladas que controlan las reacciones de PrintDeck cuando la impresora las comunica.

Fases del trabajo

Todos los valores de fase de trabajo compatibles:

unknownidlepreparingprintingpausedcompletedfailedcancelled

Actividades detalladas

Todos los valores de actividad de trabajo compatibles:

unknownstandbypreparingnozzle_heatingbed_heatinghomingbed_levelingnozzle_cleaningcalibratingfilament_changingfilament_unloadingfilament_loadingfilament_purgingprintingpausedcompletedfailedcancelled

No necesitas una entidad por cada valor. El sensor PrintDeck Activity cambia entre todas las actividades indicadas y una automatización puede reaccionar al valor que elijas.

Valores de conexión y estado

connection.state
stopped waiting_for_network connecting online offline
connection.reachability
unknown online offline
connection.detail_level
summary full
job.kind
print calibration

La disponibilidad de actividades detalladas depende de los datos que comunique la impresora conectada. El valor unknown de la API utiliza la reacción unavailable de PrintDeck como alternativa. La impresora seleccionada proporciona datos completos en tiempo real; las demás impresoras guardadas pueden proporcionar datos resumidos según el intervalo configurado de actualización de la lista de impresoras.

PAQUETE COMPLETO DE SENSORES DE ESTADO

Una solicitud a la API.
Todos los campos de estado detallado.

Utiliza este bloque en lugar del bloque anterior, más pequeño y limitado a la fase. Crea entidades para todos los campos devueltos por el endpoint de estado detallado y sigue consultando PrintDeck una sola vez por intervalo.

configuration.yaml
rest:
  - resource: "http://PRINTDECK-IP/v1/printers/1/status"
    method: GET
    headers:
      Authorization: !secret printdeck_api_bearer
    scan_interval: 10
    timeout: 5
    sensor:
      - name: "PrintDeck Printer ID"
        unique_id: printdeck_printer_1_id
        value_template: "{{ value_json.status.printer_id }}"

      - name: "PrintDeck Connection"
        unique_id: printdeck_printer_1_connection
        value_template: "{{ value_json.status.connection.state }}"

      - name: "PrintDeck Reachability"
        unique_id: printdeck_printer_1_reachability
        value_template: "{{ value_json.status.connection.reachability }}"

      - name: "PrintDeck Detail Level"
        unique_id: printdeck_printer_1_detail_level
        value_template: "{{ value_json.status.connection.detail_level }}"

      - name: "PrintDeck Update Marker"
        unique_id: printdeck_printer_1_updated_at_ms
        value_template: "{{ value_json.status.connection.updated_at_ms }}"
        unit_of_measurement: "ms"

      - name: "PrintDeck Phase"
        unique_id: printdeck_printer_1_phase
        value_template: "{{ value_json.status.job.phase }}"

      - name: "PrintDeck Job Kind"
        unique_id: printdeck_printer_1_job_kind
        value_template: "{{ value_json.status.job.kind }}"

      - name: "PrintDeck Activity"
        unique_id: printdeck_printer_1_activity
        value_template: "{{ value_json.status.job.activity }}"

      - name: "PrintDeck Job Name"
        unique_id: printdeck_printer_1_job_name
        value_template: "{{ value_json.status.job.name | default('none', true) }}"

      - name: "PrintDeck Progress"
        unique_id: printdeck_printer_1_progress
        value_template: "{{ value_json.status.job.progress_percent }}"
        availability: >-
          {{ value_json.status.connection.detail_level == 'full' and
             not value_json.status.connection.stale }}
        unit_of_measurement: "%"

      - name: "PrintDeck Elapsed"
        unique_id: printdeck_printer_1_elapsed
        value_template: "{{ value_json.status.job.elapsed_seconds }}"
        availability: >-
          {{ value_json.status.connection.detail_level == 'full' and
             not value_json.status.connection.stale }}
        device_class: duration
        unit_of_measurement: "s"

      - name: "PrintDeck Remaining"
        unique_id: printdeck_printer_1_remaining
        value_template: "{{ value_json.status.job.remaining_seconds }}"
        availability: "{{ not value_json.status.connection.stale }}"
        device_class: duration
        unit_of_measurement: "s"

      - name: "PrintDeck Current Layer"
        unique_id: printdeck_printer_1_current_layer
        value_template: "{{ value_json.status.job.current_layer }}"
        availability: >-
          {{ value_json.status.connection.detail_level == 'full' and
             not value_json.status.connection.stale }}

      - name: "PrintDeck Total Layers"
        unique_id: printdeck_printer_1_total_layers
        value_template: "{{ value_json.status.job.total_layers }}"
        availability: >-
          {{ value_json.status.connection.detail_level == 'full' and
             not value_json.status.connection.stale }}

      - name: "PrintDeck Nozzle Temperature"
        unique_id: printdeck_printer_1_nozzle_temperature
        value_template: "{{ value_json.status.temperatures.nozzle_current_c }}"
        availability: >-
          {{ value_json.status.temperatures.nozzle_current_c is not none and
             not value_json.status.connection.stale }}
        device_class: temperature
        state_class: measurement
        unit_of_measurement: "°C"

      - name: "PrintDeck Nozzle Target"
        unique_id: printdeck_printer_1_nozzle_target
        value_template: "{{ value_json.status.temperatures.nozzle_target_c }}"
        availability: >-
          {{ value_json.status.temperatures.nozzle_target_c is not none and
             not value_json.status.connection.stale }}
        device_class: temperature
        unit_of_measurement: "°C"

      - name: "PrintDeck Bed Temperature"
        unique_id: printdeck_printer_1_bed_temperature
        value_template: "{{ value_json.status.temperatures.bed_current_c }}"
        availability: >-
          {{ value_json.status.temperatures.bed_current_c is not none and
             not value_json.status.connection.stale }}
        device_class: temperature
        state_class: measurement
        unit_of_measurement: "°C"

      - name: "PrintDeck Bed Target"
        unique_id: printdeck_printer_1_bed_target
        value_template: "{{ value_json.status.temperatures.bed_target_c }}"
        availability: >-
          {{ value_json.status.temperatures.bed_target_c is not none and
             not value_json.status.connection.stale }}
        device_class: temperature
        unit_of_measurement: "°C"

      - name: "PrintDeck Chamber Temperature"
        unique_id: printdeck_printer_1_chamber_temperature
        value_template: "{{ value_json.status.temperatures.chamber_current_c }}"
        availability: >-
          {{ value_json.status.temperatures.chamber_current_c is not none and
             not value_json.status.connection.stale }}
        device_class: temperature
        state_class: measurement
        unit_of_measurement: "°C"

    binary_sensor:
      - name: "PrintDeck Data Stale"
        unique_id: printdeck_printer_1_data_stale
        value_template: "{{ value_json.status.connection.stale }}"
        device_class: problem

      - name: "PrintDeck Online"
        unique_id: printdeck_printer_1_online
        value_template: "{{ value_json.status.connection.state == 'online' }}"
        device_class: connectivity
Antes de reiniciar

Guarda el token correspondiente en secrets.yaml y sustituye PRINTDECK-IP y el ID de impresora 1. Si configuration.yaml ya contiene una sección rest de nivel superior, añade este recurso debajo en lugar de crear una segunda clave rest.

CONVIENE SABERLO

Local por diseño.
De solo lectura por diseño.

Home Assistant consulta PrintDeck; PrintDeck no envía webhooks. Mantén ambos dispositivos en una red local de confianza, no expongas el puerto de la API a internet y guarda el token Bearer en secrets.yaml.

El progreso, las temperaturas y las actividades detalladas utilizadas por las reacciones son más completos para la impresora seleccionada actualmente en PrintDeck. La conexión y el estado resumido del trabajo siguen disponibles para las demás impresoras guardadas.
