Razones para elegir PrintDeck para tu KNOMI:

  1. Más control sobre las animaciones: importa GIF, WebP animados e imágenes fijas; recorta, previsualiza y asígnalos a estados de impresión en Web Config.
  2. Estado de impresión en directo: consulta de un vistazo el progreso, el tiempo restante, las capas y las temperaturas.
  3. Vista de cámara: comprueba tu impresión directamente en KNOMI con imágenes actualizadas de cámaras locales compatibles.
  4. Información detallada: consulta temperaturas de las herramientas, filamento, ventiladores y otros datos que ofrece tu impresora.
  5. Varias impresoras en un dispositivo: guarda perfiles y cambia entre ellos en el mismo KNOMI.
  6. Integraciones: conecta los datos de la impresora con tus herramientas mediante Unified API, MQTT y Home Assistant.
  7. Puedes volver atrás: recupera el firmware original de KNOMI reinstalando el del fabricante para tu modelo.
  8. PrintDeck Cloud: vincula tu KNOMI a una cuenta y gestiónalo desde cualquier lugar mientras el dispositivo esté conectado a internet.
  9. Web Config avanzado: gestiona PrintDeck, perfiles de impresoras, animaciones, ajustes de pantalla y actualizaciones desde el navegador.
  10. Aplicaciones para iPhone, iPad, Mac y Apple Watch. Android llegará pronto.
