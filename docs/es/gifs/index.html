FORMATOS DE ENTRADA COMPATIBLES

Empieza con una animación
o una imagen estática.

Web Config convierte cada archivo compatible en un GIF listo para el dispositivo con fondo negro opaco.

ANIMADO

GIF y WebP animado

Conserva el movimiento, elige el momento útil y deja que PrintDeck convierta el fragmento en un bucle compacto.

GIF87aGIF89aWebP animado
ESTÁTICO

PNG, JPEG, WebP, AVIF y BMP

Una imagen estática se convierte en un GIF de un solo fotograma. HEIC y HEIF también funcionan si el navegador puede decodificarlos.

PNGJPEGWebPAVIFBMPHEIC / HEIF*

Los archivos de vídeo no se aceptan directamente. Convierte primero MP4, MOV o WebM a GIF o WebP animado. La compatibilidad del navegador determina si se pueden abrir HEIC y HEIF.

UN PEQUEÑO EDITOR JUSTO DONDE LO NECESITAS

Haz que encaje
antes de cargarla.

01

Haz clic o arrastra y suelta

Elige una imagen con el selector de archivos o suéltala directamente sobre una tarjeta de reacción en Web Config.

02

Amplía y recoloca

Usa el control deslizante o la rueda del ratón para ampliar de 1× a 4× y arrastra la imagen para elegir el recorte cuadrado.

03

Elige el mejor momento

Para animaciones más largas, arrastra la ventana de la línea de tiempo y selecciona un fragmento de 1 a 5 segundos. Las animaciones más cortas se usan completas.
