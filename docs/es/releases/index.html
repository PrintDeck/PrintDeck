AMOLED 1.75″

1.0.192026-09-15Última para esta pantallaConexiones más sencillas, menos interrupciones+
  • PrintDeck puede volver a encontrar las impresoras guardadas compatibles tras un cambio de IP local, conservando sus perfiles y cámaras asignadas.
  • Antes de guardar una nueva dirección se comprueba la identidad de la impresora. Las impresoras sin un identificador compatible siguen necesitando un cambio de dirección manual.
  • REST API, MQTT y la detección automática de Home Assistant tienen interruptores más claros y piden confirmación antes de desconectar aplicaciones o eliminar entidades detectadas.
  • Home Assistant propone configurar PrintDeck automáticamente cuando MQTT está activado y la detección MQTT estándar está desactivada. El acceso HTTP sigue siendo independiente.
  • Para usar la configuración mejorada, actualiza la integración PrintDeck en HACS a la versión 0.1.7 o posterior y reinicia Home Assistant. Elige HACS o la detección MQTT estándar para cada PrintDeck.

Si tu instalación es compatible, usa la actualización ofrecida en Web Config. Siguen vigentes los requisitos de instalación de fábrica anteriores.

  • Los eventos se guardan temporalmente en el dispositivo. La entrega no está garantizada y un reinicio borra el historial.
