Antes de empezar

Conecta en tres pasos

Necesitas una instancia de OctoPrint en funcionamiento y conectada a tu impresora, su dirección local y una clave API de un usuario con permiso para consultar el estado de la impresora y del trabajo. Mantén encendido el equipo de OctoPrint mientras supervisas.

  1. 01

    Prepara OctoPrint

    Abre OctoPrint y confirma que está conectado a la impresora. Crea o copia una clave API de usuario o de aplicación. La clave de aplicación hereda los permisos de su usuario; este necesita permiso para consultar el estado y los trabajos.

  2. 02

    Añade OctoPrint

    En Web Config, abre Mis impresoras → Añadir impresora → Otras impresoras. Introduce la dirección de OctoPrint, incluido el puerto si hace falta, y elige OctoPrint en Tipo de conexión.

  3. 03

    Comprobar y añadir

    Introduce un nombre y la clave API, y elige Comprobar y añadir. La prueba de conexión solo consulta el estado. Selecciona el perfil en línea para abrir su panel.

Preguntas y respuestas

¿Una conexión de OctoPrint puede mostrar varias impresoras?

Cada instancia de OctoPrint se convierte en un perfil de impresora en PrintDeck. Añade un perfil para cada instancia y selecciona la impresora que quieras seguir.

¿Y la cámara y los controles de la impresora?

Usa OctoPrint para la cámara, las miniaturas y los controles de la impresora. La conexión con PrintDeck se centra en la información del trabajo y la supervisión de temperaturas.

¿Qué pasa si cambio la dirección más adelante?

Deja la clave en blanco para conservarla si la dirección no cambia. Vuelve a introducirla cuando cambies la dirección. OctoPrint debe seguir conectado a su impresora para aparecer en línea.
