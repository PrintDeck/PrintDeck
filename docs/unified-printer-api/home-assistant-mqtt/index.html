Home Assistant with MQTT

Connect PrintDeck to Mosquitto. Choose automatic MQTT Discovery or the PrintDeck HACS integration with an MQTT connection.

  1. 01

    Prepare Mosquitto

    Install the Mosquitto broker app in Home Assistant, or use your existing local broker. Configure the MQTT integration in Home Assistant and create broker credentials for PrintDeck. Both must connect to the same broker.

  2. 02

    Connect PrintDeck

    Open Web Config > Device Settings > Unified API. Enable MQTT and enter the broker address, port and credentials. Use an address reachable from PrintDeck, not Home Assistant’s internal app name. Save, then check the connection status. HTTP and MQTT can be enabled independently.

  3. 03

    Choose one Home Assistant path

    For Home Assistant’s built-in MQTT integration, enable Home Assistant MQTT Discovery in PrintDeck. Devices and entities appear automatically; HACS is not required. For the PrintDeck integration, install it through HACS, add PrintDeck and choose MQTT as the connection type. Keep Discovery off in this case to avoid duplicate entities.

  4. 04

    Use the same automations

    Select your new state and progress entities in the existing print-finished and progress-milestone blueprints. Before switching an existing HTTP setup, update the entity selections in dashboards and automations. Do not run both paths for the same printer unless you deliberately want two sets of entities.

In the HACS MQTT setup, paste the MQTT topic root shown in PrintDeck Web Config. Home Assistant supplies its configured broker connection; do not enter the broker password again. To switch HTTP and MQTT inside an existing PrintDeck integration, use Reconfigure. This preserves its entity identities. Switching between generic MQTT Discovery and HACS requires selecting the new entities in your automations.

Read-only data, shared across connections

MQTT uses the same normalized printer data as HTTP: identity, job state, progress, timing, temperatures, tools and materials. Only the selected printer has a full live connection; other printers follow the configured list refresh. Unknown data remains unknown, and stale data is marked. MQTT does not add printer controls or camera streaming.

Connection and recovery

TLS verifies the broker certificate and hostname. Add your own CA certificate when required. Saved secrets remain on PrintDeck; empty password and CA fields preserve them. When the broker or HA restarts, PrintDeck reconnects and publishes fresh data. Availability describes the PrintDeck connection separately from each printer’s status.

Remove old Discovery entries

Before changing brokers or switching to HACS MQTT, disable Discovery while the old broker is reachable and allow cleanup to finish. If that broker cannot be reached, its retained Discovery entries may need manual removal. Renaming a printer keeps its identity; deleting a profile removes its Discovery configuration.

Keep the HTTP integration

The existing HTTP guide and HACS installation remain available. MQTT is an additional connection choice.
