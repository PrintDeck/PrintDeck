A SMALL READ-ONLY CONTRACT

Useful data.
No control surface.

The API exposes device information, printer identity, status, nozzles and material slots. It cannot start, pause or cancel a print.

GET STARTED ON YOUR LAN

From Web Config
to your first request.

  1. 01

    Open Unified Printer API

    In Web Config, open Device Settings and choose Unified Printer API above Backup & Restore.

  2. 02

    Enable and copy the token

    PrintDeck generates a random access token and stores it locally on the device.

  3. 03

    Send Bearer authentication

    Use the token in the Authorization header of every request to your PrintDeck IP address.

  4. 04

    GET unified data

    Read printer lists or status and consume the same JSON shape across supported printer types.

TRUSTED LAN BOUNDARY

Your printer secrets
stay behind PrintDeck.

The Unified Printer API never returns printer passwords, LAN access codes, serial numbers, Wi-Fi passwords, camera frames or raw vendor payloads. Keep PrintDeck on a trusted local network and do not forward its port to the internet.

No webhooks. No cloud relay. No printer-control endpoints.
