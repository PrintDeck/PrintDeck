Może być wymagany sterownik USB

KNOMI2 korzysta z mostka WCH USB–port szeregowy. W przeciwieństwie do ekranów Waveshare nie używa standardowego, natywnego połączenia USB, dlatego zanim Chrome go zobaczy, może być wymagany sterownik WCH. Wynika to z konstrukcji sprzętowej KNOMI2, a nie z PrintDeck. Kliknij poniżej, aby rozpocząć instalację i otworzyć chronioną listę urządzeń Chrome. Szukaj pozycji WCH USB Serial (cu.wchusbserial…), USB-SERIAL CH340 (COM…) albo /dev/ttyUSB…. Jeśli jej nie widzisz, zamknij listę, wybierz swój system i wykonaj poniższe instrukcje instalacji sterownika.

Instrukcja instalacji sterownika:

  1. Pobierz oficjalny sterownik WCH dla macOS.
  2. Rozpakuj pobrany plik, uruchom instalator i zezwól na rozszerzenie WCH w Ustawienia systemowe → Prywatność i ochrona jeśli macOS o to poprosi.
  3. Ponowne uruchomienie może nie być konieczne. Najpierw sprawdź połączenie tutaj. Jeśli Chrome nie widzi KNOMI2, uruchom ponownie Maca, podłącz KNOMI2 przewodem USB do transmisji danych i spróbuj ponownie.
  1. Podłącz KNOMI2 i poczekaj kilka sekund. Windows zwykle instaluje zalecany sterownik automatycznie przez Windows Update.
  2. Kliknij poniżej przycisk sprawdzania połączenia. Jeśli pojawi się USB Serial nie trzeba niczego dodatkowo instalować.
  3. Jeśli brakuje KNOMI2, pobierz oficjalny sterownik WCH dla Windows, uruchom SETUP.EXE, wybierz Zainstaluj, a następnie podłącz ponownie KNOMI2.
  1. Podłącz KNOMI2. Większość dystrybucji Linuxa ma już sterownik ch341 więc zwykle nie trzeba niczego pobierać.
  2. Jeśli port szeregowy jest zablokowany, uruchom sudo usermod -aG dialout "$USER", a następnie wyloguj się i zaloguj ponownie.
  3. Wróć tutaj i sprawdź połączenie poniżej.

PIERWSZA INSTALACJA / RESET FABRYCZNY

Przygotuj i podłącz swój ekran

  1. Przygotuj przewód USB-C do transmisji danych. Musi przesyłać dane, a nie tylko ładować urządzenia. Zwykle sprawdzi się przewód dołączony do telefonu lub dysku zewnętrznego.
  2. Podłącz ekran bezpośrednio do komputera. Podłącz końcówkę USB-C do ekranu Waveshare, a drugą do komputera PC lub Mac. Podczas pierwszej instalacji nie używaj koncentratora USB.
  3. Podłącz KNOMI2 bezpośrednio do komputera. Użyj przewodu USB-C do transmisji danych i podczas pierwszej instalacji nie korzystaj z koncentratora USB.
  4. Uruchom instalator poniżej. Wybierz urządzenie szeregowe, którego nazwa zawiera ESP32, USB, UART, JTAG lub CP210. Potwierdź pełne wymazanie, gdy pojawi się pytanie, a następnie poczekaj, aż instalacja osiągnie 100%.
  5. Uruchom instalator poniżej. Wybierz WCH USB Serial (cu.wchusbserial…), USB-SERIAL CH340 (COM…) albo /dev/ttyUSB…. Potwierdź pełne wymazanie, gdy pojawi się pytanie, a następnie poczekaj, aż instalacja osiągnie 100%.
Dostęp do USB wymaga otwarcia tej strony przez HTTPS.
Jeśli urządzenie się nie pojawia: odłącz przewód. Przytrzymaj przycisk BOOT na ekranie, podłącz ponownie USB-C, po dwóch sekundach zwolnij BOOT i spróbuj ponownie.
Jeśli KNOMI2 się nie pojawia: zamknij listę urządzeń, wykonaj instrukcje sterownika USB w czerwonej sekcji powyżej, podłącz ponownie KNOMI2 i ponownie rozpocznij instalację.
  1. Poczekaj na ekran konfiguracji Wi-Fi. Ekran wyświetli kod QR i utworzy tymczasową sieć o nazwie PrintDeck-XXXXXX, z unikalną końcówką dla tego ekranu.
  2. Połącz telefon lub komputer ze swoim ekranem. Zeskanuj kod QR aparatem telefonu albo wybierz dokładną otwartą sieć pokazaną na PrintDeck. Konfiguracja Wi-Fi powinna otworzyć się automatycznie. Hasło nie jest wymagane, a komunikat o braku internetu w tej sieci jest normalny.
  3. Jeśli konfiguracja nie otworzy się automatycznie. Pozostając połączonym z siecią konfiguracji PrintDeck, wpisz http://printdeck.local w przeglądarce. W razie potrzeby użyj http://192.168.4.1 jako adresu zapasowego.
  4. Połącz swój ekran ze zwykłą siecią Wi-Fi. Użyj opcji Skanuj sieci, wybierz swoją sieć, wpisz hasło i zapisz. Dane drukarki dodaje się osobno po skonfigurowaniu Wi-Fi.
  5. Połącz telefon lub komputer ponownie ze zwykłą siecią Wi-Fi. Ekran uruchomi się ponownie z pustym widokiem Moje drukarki i wyświetli adres Web Config.
  6. Dodaj drukarkę w Web Config. Otwórz adres wyświetlony na ekranie, dodaj drukarkę Klipper lub Bambu Lab i zapisz połączenie.

Reset fabryczny: ta opcja usuwa wszystkie ustawienia zapisane na ekranie. Nie zmienia niczego w drukarce ani jej kontrolerze.

AKTUALIZACJA FIRMWARE

Aktualizuj bez utraty ustawień

Zaktualizuj działający ekran przez USB bez usuwania zapisanej sieci Wi-Fi, drukarek, wyglądu ani innych ustawień. Ten aktualizator zapisuje wyłącznie aplikację i wybór rozruchu; partycja ustawień NVS nigdy nie jest wymazywana.

  1. Podłącz ekran bezpośrednio do tego komputera przewodem USB-C do transmisji danych.
  2. Podłącz KNOMI2 bezpośrednio do tego komputera przewodem USB-C do transmisji danych.
  3. Wybierz wersję firmware powyżej. Domyślnie wybrana jest najnowsza wersja; do przywrócenia można wybrać starszą.
  4. Uruchom aktualizację USB poniżej. Po wyświetleniu monitu wybierz urządzenie szeregowe ESP32, USB, UART, JTAG lub CP210.
  5. Uruchom aktualizację USB poniżej. Po wyświetleniu monitu wybierz WCH USB Serial (cu.wchusbserial…), USB-SERIAL CH340 (COM…) albo /dev/ttyUSB….
  6. Poczekaj, aż ekran uruchomi się ponownie. Nie odłączaj USB, gdy widoczny jest postęp aktualizacji.
Jeśli brakuje KNOMI2: wykonaj instrukcje sterownika USB w czerwonej sekcji powyżej, podłącz urządzenie ponownie, a następnie ponownie rozpocznij aktualizację.

Przygotowywanie aktualizacji…
Twoja konfiguracja pozostaje bezpieczna: ta metoda nie może zażądać ani wykonać pełnego wymazania urządzenia. Jeśli ekranu nie można zaktualizować, użyj opcji Pierwsza instalacja / Reset fabryczny wyłącznie jako opcji odzyskiwania.

Wolisz aktualizację przez Wi-Fi?

Otwórz lokalną stronę Web Config swojego ekranu i wybierz Sprawdź aktualizacje, a następnie potwierdź Zainstaluj aktualizację. Aktualizator Wi-Fi również zachowuje zapisane ustawienia.

Gratulacje!

Zeskanuj kod QR pokazany na ekranie PrintDeck lub połącz się z wyświetloną tam dokładną siecią PrintDeck-XXXXXX.

PRZEGLĄDARKA NIE JEST OBSŁUGIWANA

Otwórz ten instalator w Chrome lub Edge

Instalacja firmware przez USB wymaga Web Serial, którego ta przeglądarka nie udostępnia. Użyj komputerowej wersji Google Chrome lub Microsoft Edge na PC albo Macu.

Microsoft Edge

Przeglądarki mobilne, Safari i Firefox nie mają dostępu do portu szeregowego USB wymaganego przez ten instalator.
