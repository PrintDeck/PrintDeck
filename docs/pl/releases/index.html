Historia zaczyna się od 1.0.10 dla każdego ekranu. Każdy model ma własną numerację wersji.

AMOLED 1.75″

1.0.192026-09-15Najnowsza dla tego ekranuŁatwiejsze połączenia, mniej przerw+
  • PrintDeck może ponownie odnaleźć obsługiwane zapisane drukarki po zmianie ich lokalnego adresu IP, zachowując te same profile i przypisane kamery.
  • Przed zapisaniem nowego adresu sprawdzana jest tożsamość drukarki. Drukarki bez obsługiwanego identyfikatora nadal wymagają ręcznej zmiany adresu.
  • REST API, MQTT i automatyczne wykrywanie Home Assistant mają czytelniejsze przełączniki WŁ./WYŁ. oraz potwierdzenie przed odłączeniem aplikacji lub usunięciem wykrytych encji.
  • Home Assistant proponuje automatyczną konfigurację PrintDeck, gdy MQTT jest włączone, a standardowe MQTT Discovery wyłączone. Dostęp HTTP działa niezależnie.
  • Aby korzystać z ulepszonej konfiguracji, zaktualizuj integrację PrintDeck w HACS do wersji 0.1.7 lub nowszej i uruchom ponownie Home Assistant. Dla każdego PrintDeck wybierz HACS albo standardowe MQTT Discovery.

W przypadku zgodnej instalacji skorzystaj z aktualizacji proponowanej w Web Config. Wymagania wcześniejszej instalacji fabrycznej nadal obowiązują.

1.0.182026-09-15Niech dom reaguje na Twój wydruk+

  • Home Assistant zyskuje czujniki stanu drukarki i encje zdarzeń druku, z zachowaniem tożsamości istniejących czujników.

  • Korzystasz ze zdarzeń HACS? Zaktualizuj integrację PrintDeck do 0.1.5 lub nowszej i uruchom ponownie Home Assistant. Dla każdego PrintDeck wybierz HACS albo natywne wykrywanie MQTT.
  • Zdarzenia druku są przechowywane tymczasowo na urządzeniu. Ich dostarczenie nie jest gwarantowane, a restart usuwa historię zdarzeń.
