BUDUJ NA DANYCH Z DRUKAREK

Twój pomysł, bez protokołu każdego producenta.

Pozwól PrintDeck obsłużyć połączenie właściwe dla drukarki, a Twoja aplikacja może korzystać z małego i przewidywalnego modelu danych.

01

Lokalne dashboardy

Pokazuj postęp, czasy, temperatury i stan połączenia na ekranach ściennych lub panelach warsztatowych.

02

Integracje Home Assistant

Przekazuj ujednolicony status drukarki do lokalnych automatyzacji bez osobnego wdrażania MQTT i Moonrakera.

03

Przepływy Node-RED

Odpytuj jeden format JSON i kieruj zdarzenia drukarki do powiadomień, oświetlenia lub wewnętrznych procesów.

04

Narzędzia monitorujące

Twórz skrypty i panele serwisowe, które rozumieją dane drukarki online, offline, nieaktualne i częściowo dostępne.

ZACZNIJ W SIECI LOKALNEJ

Od Web Config
do pierwszego zapytania.

  1. 01

    Otwórz Unified Printer API

    W Web Config otwórz Ustawienia urządzenia i wybierz Unified Printer API nad Kopią zapasową i przywracaniem.

  2. 02

    Włącz i skopiuj token

    PrintDeck generuje losowy token dostępu i zapisuje go lokalnie na urządzeniu.

  3. 03

    Wyślij autoryzację Bearer

    Używaj tokenu w nagłówku Authorization każdego zapytania do adresu IP PrintDeck.

  4. 04

    Pobierz ujednolicone dane

    Odczytuj listy drukarek lub status i korzystaj z tego samego formatu JSON dla obsługiwanych typów drukarek.

GRANICA ZAUFANEJ SIECI LAN

Sekrety Twojej drukarki
pozostają za PrintDeck.

Unified Printer API nigdy nie zwraca haseł drukarki, kodów dostępu LAN, numerów seryjnych, haseł Wi-Fi, klatek z kamery ani surowych danych producenta. Trzymaj PrintDeck w zaufanej sieci lokalnej i nie przekierowuj jego portu do internetu.

Bez webhooków. Bez pośrednictwa chmury. Bez endpointów sterowania drukarką.
