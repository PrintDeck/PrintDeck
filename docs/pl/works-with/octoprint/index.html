Miej temperatury na oku

Odczytuj zgłaszane temperatury i wartości docelowe nawet dwunastu narzędzi oraz stołu, a także temperaturę komory, gdy jest dostępna. Brakujące odczyty pozostają niedostępne.

Zanim zaczniesz

Połącz w trzech krokach

Przygotuj działającą instancję OctoPrint połączoną z drukarką, jej lokalny adres i klucz API użytkownika z prawem do odczytu stanu drukarki oraz zadania. Komputer z OctoPrint musi działać podczas monitorowania.

  1. 01

    Przygotuj OctoPrint

    Otwórz OctoPrint i upewnij się, że jest połączony z drukarką. Utwórz lub skopiuj klucz API użytkownika albo aplikacji. Klucz aplikacji dziedziczy uprawnienia użytkownika; musi on mieć prawo do podglądu stanu i zadań.

  2. 02

    Dodaj OctoPrint

    W Web Config otwórz Moje drukarki → Dodaj drukarkę → Inne drukarki. Wpisz adres OctoPrint wraz z portem, jeśli jest potrzebny, i wybierz OctoPrint w polu Rodzaj połączenia.

  3. 03

    Sprawdź i dodaj

    Wpisz nazwę i klucz API, a następnie wybierz Sprawdź i dodaj. Test połączenia tylko odczytuje stan. Wybierz profil online, aby otworzyć jego pulpit.

Pytania i odpowiedzi

Czy jedno połączenie OctoPrint może pokazywać wiele drukarek?

Każda instancja OctoPrint staje się jednym profilem drukarki w PrintDeck. Dodaj osobne profile dla kolejnych instancji, a następnie wybierz drukarkę, którą chcesz obserwować.

A co z kamerą i sterowaniem drukarką?

Do kamery, miniatur wydruków i sterowania drukarką używaj OctoPrint. Połączenie z PrintDeck skupia się na informacjach o zadaniu i obserwowaniu temperatur.

Co jeśli później zmienię adres?

Przy tym samym adresie pozostaw pole klucza puste, aby zachować zapisany klucz. Po zmianie adresu wpisz go ponownie. Aby profil był online, OctoPrint musi pozostawać połączony z drukarką.
