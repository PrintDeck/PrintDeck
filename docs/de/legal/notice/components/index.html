The target linker maps retain runtime objects from the applicable board drivers
and from `esp_codec_dev`, `esp_h264`,
`esp_io_expander`, `esp_lcd_touch`, `esp_libsrtp`, `esp_lv_decoder`,
`esp_lvgl_adapter`, `esp_new_jpeg`, `esp_peer`, `esp_websocket_client`,
`cjson`, `libpng`, `mdns`, `mqtt`, `zlib`, LittleFS, LVGL and QMI8658. The target-specific maps
also retain XPowersLib, TCA9554, CO5300 and CST9217 for AMOLED, CST816S for LCD,
and GC9A01 plus CST816S for KNOMI2. `button`, `cmake_utilities`, `esp_lcd_panel_io_additions`,
`esp_lv_fs`, `esp_mmap_assets`, `freetype` and `knob` are resolved build or
adapter dependencies but contribute no retained archive object to either final
link. They remain listed so this inventory exactly covers `dependencies.lock`.

## Waveshare BSP override

`components/waveshare__esp32_s3_touch_amoled_1_75` contains PrintDeck's pinned
copy of Waveshare BSP 3.0.1, based on upstream commit
`bfeb6e6d5737178cdde78b630c8118074da0a657`. It is kept in Git because the
released firmware depends on board-specific display fixes that are not present
in the published component: software rotation for 90/270-degree orientations,
matching touch rotation, PSRAM-backed rotation storage, internal DMA staging,
TE-aware transfers and panel offsets. Keeping the override in source makes a
clean release build reproducible instead of relying on an ignored modification
inside `managed_components`.

The upstream Apache-2.0 `LICENSE` and component metadata are retained in that
directory. Future BSP upgrades must rebase and verify this override on hardware.

## Waveshare ESP32-S3 Touch LCD 1.54 reference

The square-display board integration in `main/src/platform/board_lcd_1_54.cpp`
uses the public Waveshare ESP32-S3 Touch LCD 1.54 examples as its hardware
reference, pinned during development to upstream commit
`5157db7c888e476fd57f8a95020800377447478f`. PrintDeck does not vendor that
example project or link its application code; it uses ESP-IDF drivers and the
managed CST816S, QMI8658 and ES8311 components directly. The upstream reference
is licensed under Apache-2.0.

## BIGTREETECH KNOMI2 hardware reference

The KNOMI2 integration in `main/src/platform/board_knomi2.cpp` uses the public
BIGTREETECH KNOMI repository as its hardware pinout reference, pinned during
development to commit `0c0cda214377b94b90efed274ba51b04d25c6e89`.
PrintDeck does not vendor or copy that application code and does not link it;
the target is implemented with ESP-IDF and managed Espressif GC9A01 and CST816S
drivers. The pinned upstream revision does not contain a license file, so it is
used only as factual hardware documentation.
