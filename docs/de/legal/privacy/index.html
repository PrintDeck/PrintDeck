Websitebesuche

PrintDeck verwendet weder Werbetracker noch Besucheranalysen. Diese Website wird auf GitHub Pages gehostet. GitHub Pages protokolliert die IP-Adressen der Besucher zu Sicherheitszwecken.

Der Videoplayer lädt Symbole von cdn.plyr.io. Der Installer lädt Bibliotheken von unpkg.com und cdn.jsdelivr.net sowie Firmware von dieser Website oder GitHub. Dabei werden deine IP-Adresse und technische Informationen zur Anfrage an den jeweiligen Anbieter übermittelt.

Externe Anbieter können Anfragedaten außerhalb des Europäischen Wirtschaftsraums verarbeiten. Ihre Datenschutzhinweise beschreiben die Verarbeitung, Speicherung und Schutzmaßnahmen bei internationalen Übermittlungen.

  • Datenschutzerklärung von GitHub
  • Datenschutzerklärung von jsDelivr

Browserspeicher

Die Website nutzt localStorage, um Sprache und Darstellung zu speichern. Der Videoplayer speichert außerdem Wiedergabeeinstellungen und kann seine Symbole zwischenspeichern. Diese Informationen bleiben in deinem Browser und werden von PrintDeck weder für Werbung noch für Besucheranalysen genutzt.

PrintDeck legt für diese Einträge kein automatisches Ablaufdatum fest. Du kannst sie entfernen, indem du die gespeicherten Daten dieser Website in den Browsereinstellungen löschst. Dadurch werden deine gespeicherten Einstellungen zurückgesetzt.

Browser-Installer

Der Installer lädt Firmware herunter und schreibt sie direkt aus deinem Browser auf das von dir ausgewählte USB-Gerät. Der Zugriff auf das Gerät erfordert deine Erlaubnis im Browser.

Supportnachrichten

Wenn du PrintDeck eine E-Mail sendest, erhalten wir deine E-Mail-Adresse, deine Nachricht und die von dir ausgewählten Anhänge. Wir nutzen Microsoft 365 (Office 365) für Support-E-Mails und verarbeiten die Korrespondenz, um deine Anfrage zu bearbeiten und gemeldete Probleme zu untersuchen.
