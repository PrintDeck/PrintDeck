Möglicherweise ist ein USB-Treiber erforderlich

KNOMI2 verwendet eine WCH-USB-Seriell-Brücke. Anders als die Waveshare-Displays nutzt es keine standardmäßige native USB-Verbindung, daher kann ein WCH-Treiber erforderlich sein, bevor Chrome es erkennt. Das liegt am Hardwaredesign von KNOMI2, nicht an PrintDeck. Klicke unten, um die Installation zu starten und die geschützte Geräteliste von Chrome zu öffnen. Suche nach WCH USB Serial (cu.wchusbserial…), USB-SERIAL CH340 (COM…) oder /dev/ttyUSB…. Wenn nichts davon erscheint, schließe die Liste, wähle dein System und folge der Treiberanleitung unten.

ERSTINSTALLATION / ZURÜCKSETZEN AUF WERKSEINSTELLUNGEN

Display vorbereiten und anschließen

  1. Besorge ein USB-C-Datenkabel. Es muss Daten übertragen und darf nicht nur laden. Das Kabel eines Smartphones oder externen Laufwerks funktioniert normalerweise.
  2. Verbinde das Display direkt mit deinem Computer. Stecke das USB-C-Ende in das Waveshare-Display und das andere Ende in deinen PC oder Mac. Vermeide bei der Erstinstallation einen USB-Hub.
  3. Verbinde KNOMI2 direkt mit deinem Computer. Verwende ein USB-C-Datenkabel und vermeide bei der Erstinstallation einen USB-Hub.
  4. Starte das Installationsprogramm unten. Wähle das serielle Gerät, dessen Name ESP32, USB, UART, JTAG oder CP210 enthält. Bestätige das vollständige Löschen und warte, bis die Installation 100 % erreicht.
  5. Starte das Installationsprogramm unten. Wähle WCH USB Serial (cu.wchusbserial…), USB-SERIAL CH340 (COM…) oder /dev/ttyUSB…. Bestätige das vollständige Löschen und warte, bis die Installation 100 % erreicht.
Für den USB-Zugriff muss diese Seite über HTTPS geöffnet werden.
Wenn kein Gerät erscheint: ziehe das Kabel ab. Halte die Taste BOOT am Display gedrückt, verbinde USB-C erneut, lasse BOOT nach zwei Sekunden los und versuche es noch einmal.
Wenn KNOMI2 nicht erscheint: schließe die Geräteliste, folge der USB-Treiberanleitung im roten Abschnitt oben, verbinde KNOMI2 erneut und starte die Installation noch einmal.
  1. Warte auf den WLAN-Einrichtungsbildschirm. Das Display zeigt einen QR-Code an und erstellt ein temporäres Netzwerk namens PrintDeck-XXXXXX, mit einer eindeutigen Endung für dieses Display.
  2. Verbinde ein Smartphone oder einen Computer mit deinem Display. Scanne den QR-Code mit der Smartphone-Kamera oder wähle genau das offene Netzwerk, das PrintDeck anzeigt. Die WLAN-Einrichtung sollte sich automatisch öffnen. Es ist kein Passwort erforderlich und der Hinweis, dass dieses Netzwerk kein Internet hat, ist normal.
  3. Falls sich die Einrichtung nicht automatisch öffnet. Gib, während du noch mit dem PrintDeck-Einrichtungsnetzwerk verbunden bist, http://printdeck.local im Browser ein. Verwende bei Bedarf http://192.168.4.1 als Ersatzadresse.
  4. Verbinde dein Display mit deinem normalen WLAN. Verwende Netzwerke suchen, wähle dein Netzwerk, gib das Passwort ein und speichere. Druckerdaten werden nach der WLAN-Einrichtung separat hinzugefügt.
  5. Verbinde dein Smartphone oder deinen Computer wieder mit dem normalen WLAN. Dein Display startet mit einer leeren Ansicht Meine Drucker und zeigt seine Web-Config-Adresse an.
  6. Füge deinen Drucker über Web Config hinzu. Öffne die auf deinem Display angezeigte Adresse, füge deinen Klipper- oder Bambu-Lab-Drucker hinzu und speichere die Verbindung.

Zurücksetzen auf Werkseinstellungen: diese Option löscht alle auf deinem Display gespeicherten Einstellungen. Am Drucker oder dessen Controller wird nichts geändert.

FIRMWARE-UPDATE

Aktualisieren ohne Einstellungsverlust

Aktualisiere ein funktionierendes Display über USB, ohne gespeichertes WLAN, Drucker, Darstellung oder andere Einstellungen zu löschen. Der Updater schreibt nur die Anwendung und die Startauswahl; die NVS-Einstellungspartition wird nie gelöscht.

  1. Verbinde das Display mit einem USB-C-Datenkabel direkt mit diesem Computer.
  2. Verbinde KNOMI2 mit einem USB-C-Datenkabel direkt mit diesem Computer.
  3. Wähle oben die Firmware-Version. Die neueste Version ist standardmäßig ausgewählt; für ein Rollback kann eine ältere Version gewählt werden.
  4. Starte unten das USB-Update. Wähle bei der Aufforderung das serielle Gerät ESP32, USB, UART, JTAG oder CP210.
  5. Starte unten das USB-Update. Wähle bei der Aufforderung WCH USB Serial (cu.wchusbserial…), USB-SERIAL CH340 (COM…) oder /dev/ttyUSB….
  6. Warte, bis das Display neu startet. Trenne USB nicht, solange der Update-Fortschritt angezeigt wird.
Wenn KNOMI2 fehlt: folge der USB-Treiberanleitung im roten Abschnitt oben, verbinde es erneut und starte dann das Update noch einmal.

Update wird vorbereitet…
Deine Konfiguration bleibt erhalten: dieser Weg kann keine vollständige Gerätelöschung anfordern oder ausführen. Wenn das Display nicht aktualisiert werden kann, verwende Erstinstallation / Zurücksetzen auf Werkseinstellungen nur als Wiederherstellungsoption.

Lieber über WLAN aktualisieren?

Öffne die lokale Web-Config-Seite deines Displays und wähle Nach Updates suchen, und bestätige anschließend Update installieren. Auch das WLAN-Update behält gespeicherte Einstellungen bei.

Glückwunsch!

1. Mit dem PrintDeck-Einrichtungsnetzwerk verbinden

Mit dem offenen WLAN verbinden . Es ist kein Passwort erforderlich.

Scanne den QR-Code auf dem PrintDeck-Bildschirm oder verbinde dich mit dem dort exakt angezeigten Netzwerk PrintDeck-XXXXXX.

2. PrintDeck-Einrichtungsseite öffnen

Öffne http://printdeck.local. Verwende bei Bedarf http://192.168.4.1, wähle dann dein normales WLAN und gib das Passwort ein.
