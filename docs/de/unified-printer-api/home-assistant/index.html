DIE IDEE

PrintDeck übersetzt.
Home Assistant reagiert.

PrintDeck versteht bereits das jeweilige Druckerprotokoll. Home Assistant muss die Unified Printer API lediglich in einem sicheren Intervall abfragen und die zurückgegebenen Werte als normale Entitäten verwenden.

01

Abgeschlossener Druck

Schalte eine Lampe ein, sende eine Benachrichtigung ans Smartphone oder gib bekannt, dass das Teil fertig ist.

02

Fortschrittsmarken

Reagiere beim Überschreiten von 25 %, 50 % oder 75 %, um eine Signalleuchte zu ändern oder ein Dashboard zu aktualisieren.

03

Auftrag pausiert oder gestoppt

Reagiere auf pausierte, fehlgeschlagene oder abgebrochene Aufträge, bevor du in die Werkstatt zurückkehrst.

04

Werkstattübersicht

Zeige Verbindung, Temperaturen, Restzeit und aktuelle Schicht in einem lokalen Dashboard an.

EIN STATUS, EIN LICHT

Licht einschalten
wenn ein Drucker fertig ist.

Dieses erste Beispiel überwacht die Phase eines Druckers und schaltet eine einzelne Licht-Entität ein. Ersetze die Beispiel-IP-Adresse, die Drucker-ID und die Licht-Entität durch deine eigenen Werte.

  1. 01

    API aktivieren

    Öffne Web Config auf PrintDeck, wähle Unified Printer API, aktiviere sie und kopiere das erzeugte Zugriffstoken.

  2. 02

    Drucker-ID ermitteln

    Rufe die Druckerliste ab und notiere die ID des Druckers, den du überwachen möchtest.

    Terminal
    curl http://PRINTDECK-IP/v1/printers \
  -H 'Authorization: Bearer pd_your_token_here'
  3. 03

    Token in secrets.yaml aufbewahren

    Nimm das Wort Bearer in den Wert des Secrets auf.

    secrets.yaml
    printdeck_api_bearer: "Bearer pd_your_token_here"
  4. 04

    Phasensensor hinzufügen

    Damit wird alle 10 Sekunden eine Anfrage gesendet. Ändere PRINTDECK-IP und die Drucker-ID 1 in der URL.

    configuration.yaml
    rest:
  - resource: "http://PRINTDECK-IP/v1/printers/1/status"
    method: GET
    headers:
      Authorization: !secret printdeck_api_bearer
    scan_interval: 10
    timeout: 5
    sensor:
      - name: "PrintDeck Phase"
        unique_id: printdeck_printer_1_phase
        value_template: "{{ value_json.status.job.phase }}"
  5. 05

    Home Assistant prüfen und neu starten

    Validiere das YAML in den Entwicklerwerkzeugen, starte Home Assistant neu und prüfe anschließend, ob die Entität PrintDeck Phase einen Wert besitzt.

  6. 06

    Automatisierung hinzufügen

    Ersetze light.living_room durch die Entitäts-ID deiner Lampe.

    automations.yaml
    - alias: "PrintDeck - light on when print completes"
  id: printdeck_light_on_when_print_completes
  triggers:
    - trigger: state
      entity_id: sensor.printdeck_phase
      to: "completed"
  conditions:
    - condition: template
      value_template: >-
        {{ trigger.from_state is not none and
           trigger.from_state.state in ['preparing', 'printing', 'paused'] }}
  actions:
    - action: light.turn_on
      target:
        entity_id: light.living_room
  mode: single
  7. 07

    Kurzen Testdruck starten

    Beobachte, wie die Phasenentität zu completed wechselt. Wenn sich die Lampe nicht einschaltet, öffne die Ablaufverfolgung der Automatisierung, um die Ergebnisse von Auslöser und Bedingung zu sehen.

ALLE NORMALISIERTEN ZUSTÄNDE

Nutze übergeordnete Phasen
oder detaillierte Aktivitäten.

Die Auftragsphase eignet sich für die meisten Automatisierungen. Die Auftragsaktivität stellt die detaillierten Aktivitäten bereit, die PrintDeck-Reaktionen auslösen, sofern der Drucker sie meldet.

Auftragsphasen

Alle unterstützten Werte für die Auftragsphase:

unknownidlepreparingprintingpausedcompletedfailedcancelled

Detaillierte Aktivitäten

Alle unterstützten Werte für die Auftragsaktivität:

unknownstandbypreparingnozzle_heatingbed_heatinghomingbed_levelingnozzle_cleaningcalibratingfilament_changingfilament_unloadingfilament_loadingfilament_purgingprintingpausedcompletedfailedcancelled

Du benötigst nicht für jeden Wert eine eigene Entität. Der unten gezeigte Sensor PrintDeck Activity wechselt zwischen allen aufgeführten Aktivitäten, und eine Automatisierung kann auf den gewählten Wert reagieren.

Verbindungs- und Statuswerte

connection.state
stopped waiting_for_network connecting online offline
connection.reachability
unknown online offline
connection.detail_level
summary full
job.kind
print calibration

Welche detaillierten Aktivitäten verfügbar sind, hängt von den Meldungen des verbundenen Druckers ab. Der API-Wert unknown verwendet die PrintDeck-Reaktion unavailable als Rückfallwert. Der ausgewählte Drucker liefert vollständige Live-Daten; andere gespeicherte Drucker können zusammengefasste Daten im konfigurierten Aktualisierungsintervall der Druckerliste bereitstellen.

VOLLSTÄNDIGES STATUSSENSOR-PAKET

Eine API-Anfrage.
Jedes Feld des detaillierten Status.

Verwende diesen Block anstelle des kleineren Blocks, der nur die Phase enthält. Er erstellt Entitäten für jedes vom detaillierten Status-Endpunkt zurückgegebene Feld und fragt PrintDeck dennoch nur einmal pro Intervall ab.

configuration.yaml
rest:
  - resource: "http://PRINTDECK-IP/v1/printers/1/status"
    method: GET
    headers:
      Authorization: !secret printdeck_api_bearer
    scan_interval: 10
    timeout: 5
    sensor:
      - name: "PrintDeck Printer ID"
        unique_id: printdeck_printer_1_id
        value_template: "{{ value_json.status.printer_id }}"

      - name: "PrintDeck Connection"
        unique_id: printdeck_printer_1_connection
        value_template: "{{ value_json.status.connection.state }}"

      - name: "PrintDeck Reachability"
        unique_id: printdeck_printer_1_reachability
        value_template: "{{ value_json.status.connection.reachability }}"

      - name: "PrintDeck Detail Level"
        unique_id: printdeck_printer_1_detail_level
        value_template: "{{ value_json.status.connection.detail_level }}"

      - name: "PrintDeck Update Marker"
        unique_id: printdeck_printer_1_updated_at_ms
        value_template: "{{ value_json.status.connection.updated_at_ms }}"
        unit_of_measurement: "ms"

      - name: "PrintDeck Phase"
        unique_id: printdeck_printer_1_phase
        value_template: "{{ value_json.status.job.phase }}"

      - name: "PrintDeck Job Kind"
        unique_id: printdeck_printer_1_job_kind
        value_template: "{{ value_json.status.job.kind }}"

      - name: "PrintDeck Activity"
        unique_id: printdeck_printer_1_activity
        value_template: "{{ value_json.status.job.activity }}"

      - name: "PrintDeck Job Name"
        unique_id: printdeck_printer_1_job_name
        value_template: "{{ value_json.status.job.name | default('none', true) }}"

      - name: "PrintDeck Progress"
        unique_id: printdeck_printer_1_progress
        value_template: "{{ value_json.status.job.progress_percent }}"
        availability: >-
          {{ value_json.status.connection.detail_level == 'full' and
             not value_json.status.connection.stale }}
        unit_of_measurement: "%"

      - name: "PrintDeck Elapsed"
        unique_id: printdeck_printer_1_elapsed
        value_template: "{{ value_json.status.job.elapsed_seconds }}"
        availability: >-
          {{ value_json.status.connection.detail_level == 'full' and
             not value_json.status.connection.stale }}
        device_class: duration
        unit_of_measurement: "s"

      - name: "PrintDeck Remaining"
        unique_id: printdeck_printer_1_remaining
        value_template: "{{ value_json.status.job.remaining_seconds }}"
        availability: "{{ not value_json.status.connection.stale }}"
        device_class: duration
        unit_of_measurement: "s"

      - name: "PrintDeck Current Layer"
        unique_id: printdeck_printer_1_current_layer
        value_template: "{{ value_json.status.job.current_layer }}"
        availability: >-
          {{ value_json.status.connection.detail_level == 'full' and
             not value_json.status.connection.stale }}

      - name: "PrintDeck Total Layers"
        unique_id: printdeck_printer_1_total_layers
        value_template: "{{ value_json.status.job.total_layers }}"
        availability: >-
          {{ value_json.status.connection.detail_level == 'full' and
             not value_json.status.connection.stale }}

      - name: "PrintDeck Nozzle Temperature"
        unique_id: printdeck_printer_1_nozzle_temperature
        value_template: "{{ value_json.status.temperatures.nozzle_current_c }}"
        availability: >-
          {{ value_json.status.temperatures.nozzle_current_c is not none and
             not value_json.status.connection.stale }}
        device_class: temperature
        state_class: measurement
        unit_of_measurement: "°C"

      - name: "PrintDeck Nozzle Target"
        unique_id: printdeck_printer_1_nozzle_target
        value_template: "{{ value_json.status.temperatures.nozzle_target_c }}"
        availability: >-
          {{ value_json.status.temperatures.nozzle_target_c is not none and
             not value_json.status.connection.stale }}
        device_class: temperature
        unit_of_measurement: "°C"

      - name: "PrintDeck Bed Temperature"
        unique_id: printdeck_printer_1_bed_temperature
        value_template: "{{ value_json.status.temperatures.bed_current_c }}"
        availability: >-
          {{ value_json.status.temperatures.bed_current_c is not none and
             not value_json.status.connection.stale }}
        device_class: temperature
        state_class: measurement
        unit_of_measurement: "°C"

      - name: "PrintDeck Bed Target"
        unique_id: printdeck_printer_1_bed_target
        value_template: "{{ value_json.status.temperatures.bed_target_c }}"
        availability: >-
          {{ value_json.status.temperatures.bed_target_c is not none and
             not value_json.status.connection.stale }}
        device_class: temperature
        unit_of_measurement: "°C"

      - name: "PrintDeck Chamber Temperature"
        unique_id: printdeck_printer_1_chamber_temperature
        value_template: "{{ value_json.status.temperatures.chamber_current_c }}"
        availability: >-
          {{ value_json.status.temperatures.chamber_current_c is not none and
             not value_json.status.connection.stale }}
        device_class: temperature
        state_class: measurement
        unit_of_measurement: "°C"

    binary_sensor:
      - name: "PrintDeck Data Stale"
        unique_id: printdeck_printer_1_data_stale
        value_template: "{{ value_json.status.connection.stale }}"
        device_class: problem

      - name: "PrintDeck Online"
        unique_id: printdeck_printer_1_online
        value_template: "{{ value_json.status.connection.state == 'online' }}"
        device_class: connectivity
Vor dem Neustart

Bewahre das passende Token in secrets.yaml auf und ersetze PRINTDECK-IP sowie die Drucker-ID 1. Wenn configuration.yaml bereits einen obersten rest-Abschnitt enthält, füge diese Ressource dort hinzu, statt einen zweiten rest-Schlüssel anzulegen.

GUT ZU WISSEN

Von Grund auf lokal.
Von Grund auf schreibgeschützt.

Home Assistant fragt PrintDeck ab; PrintDeck sendet keine Webhooks. Betreibe beide Geräte in einem vertrauenswürdigen lokalen Netzwerk, gib den API-Port nicht für das Internet frei und bewahre das Bearer-Token in secrets.yaml auf.

Fortschritt, Temperaturen und die detaillierten Aktivitäten für Reaktionen sind beim aktuell in PrintDeck ausgewählten Drucker am vollständigsten. Verbindung und zusammengefasster Auftragsstatus bleiben für andere gespeicherte Drucker verfügbar.
