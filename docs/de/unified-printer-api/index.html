AUF DRUCKERDATEN AUFBAUEN

Deine Idee, ohne jedes Herstellerprotokoll.

PrintDeck übernimmt die druckerspezifische Verbindung, während deine Anwendung mit einem kleinen, vorhersehbaren Datenmodell arbeitet.

01

Lokale Dashboards

Zeige Fortschritt, Zeiten, Temperaturen und Verbindungsstatus auf Wanddisplays oder Werkstatt-Panels.

02

Home-Assistant-Bridges

Speise vereinheitlichte Druckerzustände in lokale Automationen ein, ohne MQTT und Moonraker separat zu implementieren.

03

Node-RED-Flows

Frage eine JSON-Struktur ab und leite Druckerereignisse an Benachrichtigungen, Beleuchtung oder interne Abläufe weiter.

04

Monitoring-Werkzeuge

Erstelle Skripte und Service-Panels, die Online-, Offline-, veraltete und teilweise verfügbare Druckerdaten verstehen.

EIN KLEINER SCHREIBGESCHÜTZTER VERTRAG

Nützliche Daten.
Keine Steueroberfläche.

Die API liefert Geräteinformationen, Druckeridentität, Status, Düsen und Materialplätze. Sie kann einen Druck weder starten, pausieren noch abbrechen.

IM LOKALEN NETZWERK STARTEN

Von Web Config
bis zur ersten Anfrage.

  1. 01

    Unified Printer API öffnen

    Öffne in Web Config die Geräteeinstellungen und wähle Unified Printer API oberhalb von Sichern und Wiederherstellen.

  2. 02

    Aktivieren und Token kopieren

    PrintDeck erzeugt ein zufälliges Zugriffstoken und speichert es lokal auf dem Gerät.

  3. 03

    Bearer-Authentifizierung senden

    Verwende das Token im Authorization-Header jeder Anfrage an die PrintDeck-IP-Adresse.

  4. 04

    Vereinheitlichte Daten abrufen

    Lies Druckerlisten oder Statusdaten im gleichen JSON-Format für alle unterstützten Druckertypen.

GRENZE DES VERTRAUTEN LAN

Die Geheimnisse deines Druckers
bleiben hinter PrintDeck.

Die Unified Printer API gibt niemals Druckerpasswörter, LAN-Zugangscodes, Seriennummern, WLAN-Passwörter, Kamerabilder oder rohe Herstellerdaten zurück. Betreibe PrintDeck in einem vertrauenswürdigen lokalen Netzwerk und leite seinen Port nicht ins Internet weiter.

Keine Webhooks. Kein Cloud-Relay. Keine Endpunkte zur Druckersteuerung.
