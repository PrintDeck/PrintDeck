# PrintDeck website marketing assets

These images belong to the marketing website only.

- `cases/riverstone.png` - The Riverstone main product image.
- `cases/riverstone-story.png` - The Riverstone image used in its design story.
- `cases/gulios-round.png` - The Scuttle product image.
- `cases/snapmaker-u1-mini.png` - Snapmaker U1 Mini case product image.
- `cases/details/` contains three replaceable detail images for each case.
  The files are initially physical copies of the corresponding product image;
  replace a file in place to update the Case Designs page without editing HTML.
- `cases/case-collection.png` - website-only three-case collection collage.
- `cases/home-case-collection.png` - website copy of the three-case manual
  composition, kept independent so future web retouching does not alter the PDF.
- `cases/home-hero-v2.png` - dark studio landing-page hero derived from the
  three-case composition and prepared for responsive cropping.
- `competition-cover-v1.png` - 640 x 360 project cover prepared for the
  Snapmaker Innovation Fund submission.
- `home/riverstone-hero-green-cutout.png` - transparent front-facing Riverstone
  artwork used by the landing-page hero.
- `home/status-screen-cutout.png` - transparent status-screen artwork used by
  the first quick-glance feature.
- `home/riverstone-off-cutout.png` - transparent screen-off Riverstone artwork
  used by the daily-use section.
- `home/riverstone-open-design-cutout.png` - transparent Riverstone artwork for
  the public-development section.
- `home/u1-mini-cutout.png` - transparent website-only U1 Mini cutout for the
  landing page.
- `home/case-collection-front-cutout.png` - website-owned transparent case
  collection used on the landing page; it is intentionally separate from the
  manual copy.
- `home/open-design-collage-light.png` - website-only copy of the supplied
  public-development collage used by the landing page in light appearance.
- `home/open-design-collage-dark.png` - dark-appearance adaptation of that
  collage; it preserves the same product, cards, connectors and composition.

The website owns its published image copies independently from the private PDF
manual inputs. Web and print images can therefore follow different cropping,
background, composition and retouching rules.
