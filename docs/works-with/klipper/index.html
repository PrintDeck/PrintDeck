Before you begin

Connect in three steps

You need a working Klipper and Moonraker setup, the Moonraker address and port, and an API key if your server requires one. PrintDeck must be able to reach that address on your local network.

  1. 01

    Check Moonraker

    Open your usual printer interface and confirm the printer is connected. Use Moonraker’s address and API port, commonly 7125, rather than a cloud dashboard address.

  2. 02

    Add the connection

    In Web Config, open My Printers → Add printer → Other printers. Enter the address and choose Klipper / Moonraker under Connection type. Add the API key if required.

  3. 03

    Review and connect

    Review the detected printer, give it a name and choose Check & add. Select the online profile to open its dashboard.

Good to know

Questions and answers

Is this a connection to Mainsail or Fluidd?

PrintDeck connects to Moonraker, the local service used by interfaces such as Mainsail and Fluidd. You can continue using your usual interface alongside PrintDeck.

Will every Klipper printer expose every detail?

No. Tool, filament and motion details depend on your configuration. Thumbnails must be available in Moonraker’s file metadata.
