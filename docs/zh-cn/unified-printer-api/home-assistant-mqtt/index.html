Home Assistant

通过 MQTT 连接 Home Assistant

将 PrintDeck 连接到 Mosquitto。选择 MQTT 自动发现，或在 HACS 的 PrintDeck 集成中选择 MQTT 连接。

  1. 01

    准备 Mosquitto

    在 Home Assistant 中安装 Mosquitto 服务器应用，或使用现有的本地服务器。配置 Home Assistant 的 MQTT 集成，并为 PrintDeck 创建服务器凭据。两者必须连接到同一台服务器。

  2. 02

    连接 PrintDeck

    打开 Web Config > 设备设置 > Unified API。启用 MQTT 并输入服务器地址、端口和凭据。使用 PrintDeck 能访问的地址，而不是 HA 内部的应用名称。保存并检查连接状态。HTTP 和 MQTT 可独立启用。

  3. 03

    选择一种 Home Assistant 接入方式

    若使用 Home Assistant 内置 MQTT 集成，请在 PrintDeck 中启用 Home Assistant MQTT 自动发现。设备和实体会自动出现，无需 HACS。若使用 PrintDeck 集成，请通过 HACS 安装，添加 PrintDeck 并选择 MQTT 连接。此时应关闭自动发现，以避免重复实体。

  4. 04

    使用相同的自动化

    在现有的打印完成和进度里程碑蓝图中选择新的状态与进度实体。从 HTTP 切换之前，请更新仪表盘和自动化中的实体选择。除非确实需要两组实体，否则不要为同一台打印机同时启用两种方式。

在 HACS 的 MQTT 设置中粘贴 PrintDeck Web Config 显示的 MQTT 主题根路径。Home Assistant 使用已配置的服务器连接，无需再次输入密码。在现有 PrintDeck 集成内切换 HTTP 与 MQTT 时，请使用“重新配置”，以保留实体身份。在通用 MQTT 自动发现与 HACS 之间切换时，需要在自动化中选择新的实体。

共享的只读数据

MQTT 与 HTTP 使用相同的规范化数据：身份、任务状态、进度、时间、温度、工具和材料。只有选中的打印机保持完整实时连接，其他打印机按列表刷新设置更新。未知数据保持未知，过期数据会被标记。MQTT 不添加打印控制或摄像头视频传输。

连接与恢复

TLS 验证服务器证书和主机名。需要时可添加自己的 CA 证书。保存的凭据保留在 PrintDeck 上，密码和 CA 字段留空即可保留。服务器或 HA 重启后，PrintDeck 会重新连接并发布最新数据。PrintDeck 的连接可用性与各台打印机的状态分别表示。

删除旧的自动发现条目

更换服务器或切换到 HACS MQTT 前，请在旧服务器仍可访问时关闭自动发现，并等待清理完成。若无法访问旧服务器，可能需要手动删除其保留的发现条目。重命名保留打印机身份，删除配置会移除其发现配置。

保留 HTTP 集成

现有的 HTTP 指南和 HACS 安装方式保持可用。MQTT 是一种额外的连接选择。
