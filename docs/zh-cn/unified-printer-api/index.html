基于打印机数据构建

你的创意， 无需逐一适配厂商协议。

让 PrintDeck 处理打印机特定连接，你的应用只需使用小巧、可预测的数据模型。

01

本地仪表板

02

Home Assistant 桥接

03

Node-RED 流程

轮询一种 JSON 结构，并将打印机事件路由到通知、灯光或内部流程。

监控工具

构建能够识别在线、离线、过期和部分可用打印机数据的脚本与服务面板。

小巧的只读约定

实用数据。
不提供控制接口。

API 提供设备信息、打印机标识、状态、喷嘴和材料槽位。它无法开始、暂停或取消打印。

在局域网中开始

从 Web Config
到首次请求。

  1. 01

    打开 Unified Printer API

    在 Web Config 中打开设备设置，并在备份与恢复上方选择 Unified Printer API。

  2. 02

    启用并复制令牌

    PrintDeck 会生成随机访问令牌，并将其本地保存在设备上。

  3. 03

    发送 Bearer 身份验证

    在发送到 PrintDeck IP 地址的每个请求中，将令牌放入 Authorization 请求头。

  4. 04

    获取统一数据

    读取打印机列表或状态，并对所有支持的打印机类型使用相同的 JSON 结构。

可信局域网边界

你的打印机机密
始终留在 PrintDeck 后方。

统一打印机 API 绝不会返回打印机密码、LAN 访问码、序列号、Wi-Fi 密码、摄像头画面或厂商原始数据。请将 PrintDeck 保持在可信本地网络中，不要把其端口转发到互联网。

无 Webhook。无云端中继。无打印机控制端点。
