开始之前

三步完成连接

为打印机启用 PrusaLink，并确认同一网络中的其他设备可以打开它。准备好本地地址，以及对应的 PrusaLink 登录凭据或 API 密钥。

  1. 01

    在本地打开 PrusaLink

    按照 Prusa 为你所用机型提供的说明操作。从打印机或 PrusaLink 设置中复制本地地址和连接凭据。

  2. 02

    选择 PrusaLink

    在 Web Config 中，打开“我的打印机 → 添加打印机 → 其他打印机”。输入地址，在“连接类型”中选择 PrusaLink。

  3. 03

    确认登录凭据

    根据你的配置选择“用户名和密码”或“API 密钥”。输入信息，选择“检查并添加”，然后选择在线的配置。

实用须知

问题与解答

需要 Prusa Connect 账号吗？

此连接使用本地网络中的 PrusaLink。请填写 PrusaLink 的本地地址和凭据，而不是 Prusa Connect 账号信息。

每个 PrusaLink 版本提供的数据都相同吗？

可用读数因打印机和 PrusaLink 版本而异。PrintDeck 会显示本地连接提供的信息。
