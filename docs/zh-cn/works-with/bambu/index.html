掌握整个打印过程

支持的机型还可显示本地摄像头快照、打印预览图和只读 AMS 信息。具体信息取决于打印机及其固件。

开始之前

三步完成连接

准备好打印机的本地地址、序列号和 LAN 访问码。确保打印机和 PrintDeck 位于同一个可以互相访问的本地网络中。

  1. 01

    查找打印机信息

    打开打印机的网络设置，复制地址和序列号。LAN 访问码也可以在其中找到；具体页面因机型而异。

  2. 02

    添加 Bambu Lab

    在 PrintDeck Web Config 中，打开“我的打印机 → 添加打印机 → Bambu Lab”。输入名称和连接信息。

  3. 03

    连接并选择

    保存连接，然后选择在线的打印机。如果所用机型有信息缺失，可查看 Web Config 中的兼容性报告。报告不会自动发送。

问题与解答

所有机型显示的信息都相同吗？

不相同。摄像头快照、打印预览图和 AMS 详情取决于机型及其提供的本地数据。PrintDeck 显示可用的读数，缺失的数值会保持为不可用。

能开始或停止打印吗？

PrintDeck 专注于状态查看。请通过打印机或平时使用的软件开始、暂停或停止任务。
