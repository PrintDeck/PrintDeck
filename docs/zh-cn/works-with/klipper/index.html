开始之前

三步完成连接

你需要正常运行的 Klipper 和 Moonraker、Moonraker 的地址及端口，以及服务器要求时所需的 API 密钥。PrintDeck 必须能够通过本地网络访问该地址。

  1. 01

    检查 Moonraker

    打开平时使用的打印机界面，确认打印机已连接。使用 Moonraker 的地址和 API 端口（通常为 7125），不要填写云端控制面板的地址。

  2. 02

    添加连接

    在 Web Config 中，打开“我的打印机 → 添加打印机 → 其他打印机”。输入地址，在“连接类型”中选择 Klipper / Moonraker。如有要求，请填写 API 密钥。

  3. 03

    确认并连接

    确认检测到的打印机，为其命名，然后选择“检查并添加”。选择在线的配置即可打开其仪表盘。

问题与解答

这是连接 Mainsail 或 Fluidd 吗？

PrintDeck 连接的是 Moonraker，它也是 Mainsail、Fluidd 等界面使用的本地服务。使用 PrintDeck 的同时，你可以继续使用熟悉的界面。

每台 Klipper 打印机都会提供所有详情吗？

不一定。工具、耗材和运动详情取决于你的配置。缩略图需要存在于 Moonraker 的文件元数据中。
