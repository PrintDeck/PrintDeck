开始之前

三步完成连接

准备好已连接打印机并正常运行的 OctoPrint 实例、它的本地地址，以及有权读取打印机状态和任务信息的用户 API 密钥。查看状态期间，请保持 OctoPrint 主机运行。

  1. 01

    准备 OctoPrint

    打开 OctoPrint，确认它已连接打印机。创建或复制用户 API 密钥或应用 API 密钥。应用密钥继承所属用户的权限，该用户需要具备查看状态和任务的权限。

  2. 02

    添加 OctoPrint

    在 Web Config 中，打开“我的打印机 → 添加打印机 → 其他打印机”。输入 OctoPrint 地址，必要时带上端口，并在“连接类型”中选择 OctoPrint。

  3. 03

    检查并添加

    输入名称和 API 密钥，然后选择“检查并添加”。连接检查仅读取状态。选择在线的配置即可显示其仪表盘。

实用须知

问题与解答

一个 OctoPrint 连接可以显示多台打印机吗？

每个 OctoPrint 实例对应一个 PrintDeck 打印机配置。为不同实例分别添加配置，再选择想要查看的打印机。

摄像头和打印机控制功能呢？

摄像头、打印缩略图和打印机控制功能请继续使用 OctoPrint。PrintDeck 连接专注于任务信息和温度查看。

以后修改地址会怎样？

地址不变时，将密钥留空即可保留已保存的密钥。更改地址时，需要重新输入密钥。OctoPrint 必须保持与打印机连接，才会显示为在线。
