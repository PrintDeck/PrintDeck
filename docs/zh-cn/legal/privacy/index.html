隐私与浏览器存储

网站访问 保存的偏好设置 支持邮件

本声明适用于 PrintDeck 网站、浏览器安装程序及支持往来邮件。如有隐私问题，请通过以下邮箱联系 PrintDeck： support@printdeck.xyz.

网站访问

PrintDeck 不使用广告跟踪器或访客分析工具。本网站托管于 GitHub Pages，该服务会出于安全目的记录访客的 IP 地址。

视频播放器从 cdn.plyr.io 加载图标。安装程序从 unpkg.com 和 cdn.jsdelivr.net 加载库，并从本网站或 GitHub 下载固件。这些请求会将你的 IP 地址和请求的技术信息发送给相应服务商。

外部服务商可能在欧洲经济区以外处理请求数据。其隐私声明说明了数据处理、保留及跨境传输的保障措施。

  • GitHub 隐私声明
  • jsDelivr 隐私政策

浏览器存储

本网站使用 localStorage 记住你的语言和外观设置。视频播放器还会保存播放偏好，并可能缓存图标。这些信息保留在你的浏览器中，PrintDeck 不将其用于广告或访客分析。

PrintDeck 未为这些条目设置自动过期时间。你可以在浏览器设置中清除本网站存储的数据，将其删除。此操作会重置已保存的偏好设置。

浏览器安装程序

安装程序下载固件，并直接从浏览器写入你选择的 USB 设备。访问设备需要你在浏览器中授权。

支持邮件

当你向 PrintDeck 发送邮件时，我们会收到你的邮箱地址、邮件内容以及你选择发送的附件。我们使用 Microsoft 365（Office 365）处理支持邮件，并处理这些往来邮件以回应你的请求及调查所报告的问题。

Microsoft 隐私声明

我们基于回复咨询和解决问题的合法利益处理支持请求。如果你的咨询涉及与我们订立合同，我们会处理必要信息，以应你的要求采取订立合同前的措施。

我们保留往来邮件的时间以处理你的请求及继续相关沟通所需的时间为限。你可以联系我们申请删除。

兼容性报告不会自动发送：你可以自行决定是否通过邮件发送报告。GitHub 问题是公开的，请勿在公开问题中包含密码、访问码或其他隐私信息。
