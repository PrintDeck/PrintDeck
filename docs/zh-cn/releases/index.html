选择你的屏幕

每款屏幕的历史记录从 1.0.10 开始，各型号独立编号。

AMOLED 1.75″

1.0.192026-09-15此屏幕的最新版本连接更轻松，中断更少+
  • 受支持的已保存打印机更换本地 IP 地址后，PrintDeck 可重新找到它们，并保留原有配置和摄像头关联。
  • 保存新地址前会核对打印机身份。没有受支持身份标识的打印机仍需手动更新地址。
  • REST API、MQTT 和 Home Assistant 自动发现采用更清晰的开关，断开应用连接或移除自动发现的实体前需要确认。
  • 启用 MQTT 并关闭标准 MQTT 自动发现后，Home Assistant 会提供 PrintDeck 自动设置入口。HTTP 访问独立运行。
  • 要使用改进的设置流程，请将 HACS 中的 PrintDeck 集成更新至 0.1.7 或更高版本，并重启 Home Assistant。每台 PrintDeck 请选择 HACS 或标准 MQTT 自动发现其中一种方式。

对于兼容的安装，请使用 Web Config 提供的更新。此前要求的出厂安装步骤仍然适用。

更新你的屏幕
1.0.182026-09-15让家随打印进度作出响应+
  • 将打印机状态、进度和温度发送到自己的本地 MQTT 代理，并在 Web Config 中配置连接。
  • 在本地 Home Assistant 自动化中使用打印开始、进度里程碑和需关注事件，通过 MQTT 自动发现简化设置。
  • Home Assistant 新增打印机状况传感器和打印事件实体，同时保留现有传感器标识。
  • 对于通过定期状态摘要检查的打印机，也可获取已知进度和已用时间。
  • PrintDeck Camera 启动更可靠，缩放构图和旧画面处理也有所改进。
  • 使用 HACS 事件？请将 PrintDeck 集成更新至 0.1.5 或更高版本并重启 Home Assistant。每台 PrintDeck 请选择 HACS 或原生 MQTT Discovery 其中一种。
  • 打印事件暂时保存在设备上。不保证事件必达，重启会清空事件历史。

对于兼容的安装，请使用 Web Config 提供的更新。此前要求的出厂安装步骤仍然适用。

更新你的屏幕
1.0.172026-09-14更多摄像头，更多打印机选择。+
  • 在本地网络中查找 PrintDeck Camera，并通过屏幕或 Web Config 将其分配给打印机。
  • 滑动切换摄像头，轻点放大预览，并集中管理所有摄像头分配。
  • 可在本地网络中发现和监控 TinyMaker 打印机，并在保存前测试连接。
  • 配置备份包含摄像头分配和设置。引入新的摄像头管理功能时会保留现有设备设置。
  • 为打印机分配 PrintDeck Camera 后，其卡片会显示摄像头图标。
  • AMOLED 摄像头预览利用更多屏幕空间，切换摄像头页面时播放一次导航提示音。
  • 在 AMOLED 上，可将自定义反应存储在 FAT32 microSD 卡中。现有图片会先复制并校验，再删除设备内的副本。
  • 在 AMOLED 上，开机、25/50/75% 进度节点和 HMS 警告使用提示音代替语音。主要打印事件、关机和重启仍保留语音通知。

对于兼容的安装，请使用 Web Config 提供的更新。此前要求的出厂安装步骤仍然适用。
