什么时候听，由你决定

在 PrintDeck 网页界面中开启。

适用于支持 Hi ESP! 的 AMOLED 1.75″ 和 LCD 1.54″ 版 PrintDeck。KNOMI 设备不支持此功能。

  1. 01

    打开 PrintDeck 网页面板

    将手机或电脑连接到同一 Wi-Fi 网络，打开设备 Web Config 屏幕上显示的网址。

  2. 02

    选择 HI ESP!

    在 PrintDeck 网页面板中打开“设备设置”，然后选择 HI ESP!，阅读麦克风和隐私说明。

  3. 03

    开启聆听

    点击“开启 Hi ESP!”。“已启用”状态和页首的 HI ESP! 标识会确认功能已开启。PrintDeck 会记住你的选择。

  4. 04

    检查声音和打印机

    开启声音，并将音量调至零以上，以便听到回答。选择一台在线打印机，设置好时区，即可获知预计完成时间。

一次一个问题

唤醒、稍等、提问。

  1. 说“Hi ESP!”

    即使屏幕已关闭，PrintDeck 也会唤醒屏幕，并重新开始屏保倒计时。

  2. 等它回答“Yes?”

    然后在 7 秒内说出英语指令。可以使用下方列表中的任意说法。

  3. 听取回答

    等 PrintDeck 说完后，再次说“Hi ESP!”。如果未识别到指令，请重新说出唤醒词。

你的声音留在这里

你的声音，你做主。

你的语音留在 PrintDeck 上。不保存录音，不向打印机或云端发送音频。连语音回答也在设备上生成，无需语音服务账户。

是否聆听，由你决定

Hi ESP! 默认关闭。开启后，麦克风会持续监听唤醒词，包括屏保运行和屏幕关闭时。

随时关闭

在 PrintDeck 网页面板 → 设备设置 → HI ESP! 中，选择“关闭 Hi ESP!”即可停止麦克风聆听。将扬声器静音只会关闭回答声音，不会关闭麦克风。

打印信息留在本地

PrintDeck 通过家庭网络获取所选打印机的状态。识别语音不需要互联网；获取最新打印信息仍需要连接打印机。
