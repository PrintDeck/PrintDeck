为 KNOMI 硬件选择 PrintDeck 的理由：

  1. 更自由地控制动画：导入 GIF、动态 WebP 和静态图片，在 Web Config 中裁剪、预览，并将其分配给打印状态。
  2. 实时打印状态：一眼查看进度、剩余时间、层数和温度。
  3. 摄像头视图：通过受支持的本地摄像头刷新画面，直接在 KNOMI 上查看打印情况。
  4. 详细打印机信息：查看工具温度、耗材、风扇及打印机提供的其他数据。
  5. 一个设备管理多台打印机：保存打印机配置，并在同一个 KNOMI 上切换。
  6. 工具集成：通过 Unified API、MQTT 和 Home Assistant，将打印机数据接入自己的工具。
  7. 保留回归选择：重新安装适用于你所用型号的厂商固件，即可恢复原版 KNOMI 固件。
  8. PrintDeck Cloud：将 KNOMI 与账户配对，设备联网时即可随时随地管理。
  9. 功能丰富的 Web Config：通过浏览器管理 PrintDeck、打印机配置、动画、显示设置和更新。
  10. 适用于 iPhone、iPad、Mac 和 Apple Watch 的应用。Android 即将推出。
