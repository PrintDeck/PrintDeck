安装流程。

USB 驱动程序来自 KNOMI2 的 WCH USB 转串口硬件，而不是 PrintDeck。之后的所有步骤都已设计为清晰的桌面浏览器引导流程。

  1. 01

    使用 USB-C 连接

    使用 USB-C 数据线将 KNOMI2 直接连接到电脑。首次安装时请避免使用 USB 集线器。

  2. 02

    让系统识别设备

    Windows 通常会通过 Windows Update 自动安装 WCH 驱动程序。

    Linux 在大多数发行版上可直接使用，可能只需处理串口权限。

    macOS 可能需要安装 WCH 官方驱动程序，并在“隐私与安全性”中批准一次，Chrome 才能识别 KNOMI2。

  3. 03

    安装 PrintDeck

    在桌面版 Chrome 或 Edge 中打开安装程序。选择 KNOMI2，再选择“首次安装 / 恢复出厂设置”，确认完全擦除并等待进度达到 100%。显示屏会重启并进入全新的 PrintDeck 体验。

KNOMI2 常见问题解答

了解会发生什么变化。
无需修改打印机。

清楚解答 PrintDeck 安装、反应动画自定义，以及如何使用打印机已有数据等问题。

我需要编辑 printer.cfg 或安装 KNOMI 专用宏吗？

不需要。PrintDeck 会读取打印机已通过 Moonraker 提供的标准状态数据。实时打印状态、进度、温度、层数和时间无需 PrintDeck 专用宏，也无需修改 G28、热床调平或其他打印机宏。只有当打印机上报了足够可靠的信息时，才会显示对应的特定反应动画。

无需 PlatformIO 或重新构建固件，也能添加自己的 GIF 吗？

可以。打开 Web Config，选择可用的反应动画位，上传 GIF，并在应用前预览。每个动画位都能单独自定义，也可随时恢复内置动画；无需 C 数组、VS Code 项目或重新构建固件。

PrintDeck 是否会显示实用的打印信息，而不只是动画？

可以。从反应动画页面滑动，即可查看打印进度、剩余时间、层数、当前及目标温度、活动工具，以及打印机提供的运动、风扇或加热器数据。Moonraker 安装最多可显示十二个挤出机的信息。

无需云服务也能查看打印机摄像头吗？

可以，但打印机及其本地摄像头来源必须受支持。打开摄像头页面时，PrintDeck 会直接连接本地网络中的摄像头。不需要 PrintDeck 云账户或远程摄像头代理。

每次更新后都需要通过 USB 重新刷写 KNOMI2 吗？

通常不需要。首次安装 PrintDeck 使用浏览器引导式安装器。后续受支持的版本可通过无线方式安装，同时保留配置的 USB 更新可作为恢复选项。
