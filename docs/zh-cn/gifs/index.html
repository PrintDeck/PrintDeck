01

点击或拖放

使用文件选择器选择图片，或直接将其拖放到 Web Config 的反应动画卡片上。

02

缩放并重新定位

使用滑块或鼠标滚轮进行 1×–4× 缩放，然后拖动图片选择方形裁剪区域。

03

选择最佳片段

对于较长的动画，可拖动时间轴窗口并选择 1–5 秒的片段。较短的动画会完整使用。
