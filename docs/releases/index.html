1.0.212026-09-17Latest for this displayOctoPrint, now on your display+
  • Add your OctoPrint printer with its local address and API key. PrintDeck checks the connection before saving it.
  • Follow job status, progress and available time estimates, plus reported temperatures for up to twelve tools, the bed and chamber.
  • Add separate profiles for separate OctoPrint instances, check their availability in My Printers and select the printer you want to follow.
  • Recognize OctoPrint by its colour logo on the dashboard. Setup guides are available in all six languages.
  • This connection monitors your printer. Continue using OctoPrint for camera images, print thumbnails and printer controls.

For compatible installations, use the update offered in Web Config. Earlier factory-install requirements still apply.

1.0.202026-09-16Faster printer discovery, easier setup+
  • Find supported printers sooner, including TinyMaker, while results appear during the network search.
  • Choosing Add pauses the search before checking the connection. Back or a successful addition resumes from the same point; closing the window stops it. An unused pause expires after five minutes.

For compatible installations, use the update offered in Web Config. Earlier factory-install requirements still apply.

Update your display
1.0.192026-09-15Easier connections, fewer interruptions+
  • PrintDeck can find supported saved printers again after their local IP address changes, keeping the same profiles and camera assignments.
  • Recovery checks the printer identity before saving a new address. Printers without a supported identity still need a manual address update.
  • REST API, MQTT and automatic Home Assistant Discovery have clearer ON/OFF switches, with confirmation before disconnecting applications or removing discovered entities.
  • Home Assistant offers automatic PrintDeck setup when MQTT is enabled and standard MQTT Discovery is off. HTTP access remains independent.
  • For the improved setup flow, update the PrintDeck HACS integration to 0.1.7 or later and restart Home Assistant. Choose either HACS or standard MQTT Discovery for each PrintDeck.

For compatible installations, use the update offered in Web Config. Earlier factory-install requirements still apply.

1.0.182026-09-15Let your home follow your print+
  • Send printer status, progress and temperatures to your own local MQTT broker. Configure the connection in Web Config.
  • Use print starts, progress milestones and attention events in local Home Assistant automations, with MQTT discovery to simplify setup.
  • Home Assistant gains printer-condition sensors and print-event entities while keeping existing sensor identities.
  • Known progress and elapsed time are also available for printers checked through periodic status summaries.
  • PrintDeck Camera starts more reliably, with improved zoom framing and handling of old frames.
  • Using HACS events? Update the PrintDeck integration to 0.1.5 or later and restart Home Assistant. Choose HACS or native MQTT Discovery for each PrintDeck.
  • Print events are held temporarily on the device. Delivery is not guaranteed, and a restart clears the event history.

For compatible installations, use the update offered in Web Config. Earlier factory-install requirements still apply.

1.0.172026-09-14More cameras. More printer choices.+
  • Find PrintDeck Cameras on your local network and assign them to printers from the display or Web Config.
  • Swipe between cameras, tap to enlarge a preview and manage all your camera assignments in one place.
  • Discover and monitor TinyMaker printers on your local network, with a connection test before saving.
  • Camera assignments and settings are included in configuration backups. Existing device settings are kept when the new camera management is introduced.
  • Printer cards show a camera icon when a PrintDeck Camera is assigned.
  • AMOLED camera previews use more of the display, with one navigation sound when switching camera pages.
  • On AMOLED, store custom reactions on a FAT32 microSD card. Existing images are copied and checked before the internal copies are removed.
  • On AMOLED, startup, 25/50/75% progress milestones and HMS warnings use sounds instead of spoken messages. Voice notifications remain for key print events, shutdown and restart.

For compatible installations, use the update offered in Web Config. Earlier factory-install requirements still apply.
