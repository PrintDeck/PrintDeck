How it works

  1. 1

    Say “Hi ESP!”

    PrintDeck wakes the display and restarts the screen saver countdown.

  2. 2

    Wait for “Yes”

    Then say a command in English within 7 seconds.

  3. 3

    Hear the answer

    PrintDeck answers in English, then listens for “Hi ESP!” again. If no command is recognized, simply start again.

API token

Send this token as an Authorization: Bearer header. It is different from a printer LAN access code.

—

Keep PrintDeck on a trusted local network. The API is read-only, but anyone with this token can read printer names, addresses and status data.

GET /v1/info

PrintDeck, firmware and network details without passwords.

GET /v1/printers

Saved printers in one safe, normalized format.

GET /v1/printers/status

Compact status for every saved printer.

GET /v1/printers/{id}

Identity, address and supported data groups.

GET /v1/printers/{id}/status

Job state, progress, time and available temperatures.

GET /v1/printers/{id}/nozzles

Tools, materials and current or target temperatures.

GET /v1/printers/{id}/materials

AMS, AMS Lite and external spool data when available.

Request throttling enabled: 1 request per second. Faster requests return HTTP 429 Too Many Requests.

No controls, webhooks or cloud account. Open the complete API guide (PDF).
