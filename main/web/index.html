Move your complete PrintDeck setup to a safe encrypted file and restore it on compatible PrintDeck hardware.

Private by design. Encryption and decryption happen locally between this browser and PrintDeck. Nothing is uploaded to a cloud service. Store the password somewhere safe—without it, the backup cannot be opened or recovered.
